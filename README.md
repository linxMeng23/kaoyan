# 考研数学学习笔记

个人考研数学（数学一/二/三·高等数学部分）的复习仓库，记录基础笔记、解题方法、专题总结与每日学习计划。

## 目录结构

```
shuxue/            数学复习主目录
├── 00 数学题解答模板.md        解题作答的固定模板与规范
├── 01 ~ 12 *.md                按章节的知识点笔记（函数极限、数列极限、连续性、
│                               导数、积分、定积分应用、微分中值定理、泰勒展开等）
├── *-讲解笔记.html             专题讲解（不定积分解题方法、等价无穷小）
├── 复盘-*.md / 类题-*.md       错题复盘与类题训练
├── 凯哥/                       课程讲义 PDF（基础上册、进阶解题方法）
├── 每日计划/                   每日学习计划
└── 题目复制/                   典型例题整理
```

## 内容概览

- **基础笔记**：高数上册核心章节，从函数极限到微分中值定理、方程的根与零点判据
- **方法专题**：不定积分解题方法、等价无穷小、泰勒双边展开防错、多项式零点重数判据等速查清单
- **实战**：解题模板、错题复盘、类题巩固、每日学习计划
