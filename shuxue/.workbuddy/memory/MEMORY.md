- 以根目录 `00数学题解答模板.md` 为准，答题前先读。六节：题目 → 考点定位 → 考场分析 → 解题步骤 → 答案（`\boxed{}`）→ 易错提醒（1–2 条）。
- 考场分析分档：直接构造型两行（题面长相／倒推链）；需挑工具型四行——① 题面长相 ② 第一步动作（对照模板第三节 12 条）③ 倒推链「要证 A ⟸ 只需证 B ⟸ …」写到能落笔 ④ 坑与临界／预计用时。
- 解题步骤走六步骨架：看结构 → 等价变形（取对数／去分母／去根号）→ 构造函数 → 算端点值 → 逐阶求导判号（通分→因式分解→判因子；判不出求二阶导；再判不出写「只需证 g>0」引入新 g 重走）→ 逐级回推。每求一次导配一个端点值，每降一级导消一层不确定。

## 术语硬约定

- 凹凸按中文教材（同济／考研口径）：$f''>0$ = **凹**（弦之下、碗口朝上）= 英文 convex；$f''<0$ = 凸。结论链：三斜率严格递增 ⟺ $f'$ 严格增 ⟺ $f''>0$（严格凹）。

## 内部数值核验

- 脚本放 `.workbuddy/tmp/`，managed python 跑。不等式余量：归一化（除 $x^3$、$x^7$）比绝对余量可靠；余量阶 ≥7 须 `decimal` 60 位。
- 积分/原函数核验用**复数步长法**：`cmath` 重写原函数，$f'(z)\approx\mathrm{Im}\,f(z+ih)/h$、$h=10^{-30}$，相对误差 $\sim10^{-15}$，一点定案。Richardson 中心差分 $h$ 过小会出 $10^{-8}$ 级假失败。
- 坑：原函数含 $\ln$ 且测试点真数为负 → 复数步长跨分支割线，报 $10^{30}$ 级假失败；改实值 $\ln|\cdot|$ + 实中心差分（$\sim10^{-12}$），或只取真数为正的区间。
- 凡 $1/(1+x^{2k})$ 族原函数必须过数值导数再交付（曾凭记忆误写"标准形"，实测误差 17%~3500%）。
- 自适应 Simpson 假收敛陷阱（2026-09-27 实测）：被积函数在「区间端点与中点」上全部取 $0$ 时（例：$x\,g(x)$ 而 $g$ 在 $0,\frac\pi2,\pi$ 处为 0），首轮估计与细分估计同为 $0$，程序认为已收敛、直接返回 $0$。凡被积函数含 $|\cdot|$、取整或分段，先在折点处分段再积分，否则会拿到 0 级假结果。
