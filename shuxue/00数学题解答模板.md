# 数学题解答模板（使用说明）

> 本文件已精简：**回答数学问题时直接按下方模板作答，不再自动修改、追加任何笔记文档。**
>
> 2026-09-20 重写：针对「模板总是从很超前的步骤起步，看不出这一步是怎么冒出来的」这一问题。改动集中在两处——**「考场分析」由一句结论改成倒推链**；**「解题步骤」每引入一个新对象，必须先交代它为什么在这里出现**。
>
> 2026-09-20 二次修订：**「答案」节去掉与解题步骤重复的推理链**；**「考场分析」按题分档**（直接构造型两行、需要挑工具型四行），第 4 行并入预计用时；**「易错提醒」改为写成可操作的动作**。

## 一、总骨架：六步，一步不能省

证明型题目（不等式、恒等式、条件判断）固定走这条线。写解答就是走这条线，不是想到哪写到哪。

| 步 | 动作 | 纸上应当出现的东西 |
|---|---|---|
| 0 | **看结构** | 一句「注意到……」：区间对称吗？含对数／根号／幂指吗？分式还是整式？结论是 $f>0$ 型还是 $A<f<B$ 型？给的是 $f''$ 的符号吗？ |
| 1 | **等价变形** | 「原式等价于……」：取对数、去分母、同乘去根号、分离参数。目标是化成好求导的形状 |
| 2 | **构造函数** | 令差函数等于不等式左端减右端。必须写清令它的理由（两端相减／取对数后相减／移项） |
| 3 | **算端点值** | $f(0)$（或 $f(1)$、$f(\frac{\pi}{2})$、两端点极限），逐个算出，标在旁边 |
| 4 | **逐阶求导判号** | 一阶导 → 通分 → 因式分解 → 判各因子符号；判不出就求二阶导；再判不出就写「只需证 $g(x)>0$」，引入新函数 $g$，回到第 2 步重走 |
| 5 | **逐级回推** | 二阶导符号 → 一阶导单调，配合一阶导端点值 → 一阶导符号 → 原函数单调，配合原函数端点值 → 原函数符号 → 原不等式 |
| 6 | **收尾** | 「故……即……，证毕」 |

第 3 步和第 5 步是一对：**每求一次导，就配一个端点值**；每降一级导，就消掉一层不确定。端点值就是符号的落脚点——这是整套流程能自动往下走的根本原因。

## 二、回答模板

```markdown
## 题目
（复述题意，明确已知条件与所求；条件缺失时先在这里注明）

## 考点定位
（一句话：属于哪一章／哪个考点，用到哪些知识点、公式）

## 考场分析
（按题分档：**直接构造型**写两行，**需要挑工具型**——涉及变形、泰勒、中值定理、参数——写四行。下面标注了每行属于哪一档）

1. **题面长相**（两档都写）：条件与结论的字面特征。如「区间 $(-1,1)$ 对称」「结论是 $A<f<B$」「给的是 $f''>0$」「含参数 $k$ 且 $k\ge k_0$」。
2. **第一步动作**（只有挑工具型写）：由长相直接决定，对照第三节的对照表取值写出。如「对称 ⟹ 先查奇偶性，只需证半区间」。
3. **倒推链**（两档都写）：把「要证什么 ⟸ 只需证什么 ⟸ 只需证什么」一路写到能落笔的那一步。如：证 $f(x)\ge0$ ⟸ 证 $f$ 在 $x>0$ 递增 ⟸ 证 $f'(x)\ge0$ ⟸ 证 $f''(x)\ge0$，再靠 $f(0)=f'(0)=0$ 兜住符号。**这条链是解答里每一行的出处，先想清楚这条链，再落笔。**
4. **坑与临界 / 预计用时**（只有挑工具型写）：易错点；参数是否恰好是临界值；等号在哪里取到；本题大概用时。

## 解题步骤
（按第一节六步走。**每引入一个新对象——新函数、二阶导、极限、中值定理、泰勒展开、放缩——先用一句话交代它为什么出现在这里**，见第四节。正负号、移项、简单合并等机械步骤可省。**按考场状态一次写到底**：想清楚再落笔，落笔后只往前推、不回头核对。**不使用 $u$、$v$ 之类中间记号代值**，详见「配套规则」第 3 条）

## 答案
（只写结论式加 $\boxed{\dots}$，一行结束。推理链在「解题步骤」里已经写完，此处不再重复，避免两处写法不一致）

## 易错提醒
（1–2 条，**必须写成「下次遇到就做这个动作」的形式**，不写知识陈述。例如不写「注意 $\ln(1+x)<x$」，要写「判 $f''$ 符号时，先写下 $\ln(1+x)<x$ 再放缩」。知识点已经有了，动作才是可迁移的）
```

## 三、题型 → 第一步动作对照表

拿到题先在这张表里找长相，找不到再自己想。这张表就是「考场分析」中**第一步动作**那一行的取值来源。

| 题面长相 | 第一步动作 |
|---|---|
| 区间对称，如 $(-1,1)$、$(-a,a)$ | 先查奇偶性，偶（奇）函数只需证一半区间 |
| 出现幂指结构、或若干因式相乘 | 取对数，把乘积与幂化成和 |
| 出现根号与对数相乘、双重根号 | 乘（除）一个正量去掉根号，化无理为有理 |
| 分式与常数比大小 | 乘分母（先说明分母恒正）去分母，化分式为整式 |
| 结论形如 $A<f(x)<B$ | 先算 $f$ 在两端的极限或函数值，$A,B$ 就是这两个值；再证 $f$ 单调 |
| 结论是一个乘积非负 | 转成分段讨论，用分界点的函数值与单调性 |
| 题设给了 $f''$ 或 $f^{(4)}$ 的符号 | 泰勒展开到对应阶，扔余量。余量符号 = 该阶导符号 × 幂符号 |
| 题设给了 $f(x)>0$ 且 $f''f-(f')^2>0$ | 想到 $(\ln f)''$ 的分子，先令 $g=\ln f$ 把题化成凹凸题 |
| 结论是「充要条件」 | 分两段写：「从前推后」「从后推前」，不写「必要性／充分性」 |
| 出现两端函数值之差与自变量之差之比 | 拉格朗日（或 Cauchy）中值定理。得 $\xi$ 后不追问 $\xi$，改估导函数在 $\xi$ 所在区间上的界 |
| 含参数 $k$，条件写成 $k\ge k_0$ | 先判断 $k_0$ 是不是**临界值**：即让某个最小值恰好取到 $0$ 的那个数；是则说明，不是则给出真实临界值 |
| 要证 $f'(x)$ 单调 | 回到「差商递增」这一等价形式，或两次中值定理比较两个中值点的导数值 |

## 四、在哪些地方必须交代来路

这一节是本次重写的核心。下面六种动作，**每一次出现都必须先写一句来源**，否则就是「超前步骤」。

1. **令差函数**——先写「不等式两端相减」，或「取对数后两端相减」，再令。
2. **求二阶导**——先写「一阶导的符号判不出」，再求二阶导。
3. **引入新函数 $g$**——先写「一阶导的符号归结为证 $g(x)>0$」，再令 $g$。
4. **用中值定理**——先写「题中出现两端函数值之差与自变量之差之比」，再用。
5. **泰勒展开**——先写「题设给了某阶导的符号，且要证的结论含该幂次」，再展开，并说明扔余量的理由。
6. **放缩**——先写所依据的已知不等式（$\sin x\le x$、$x-\sin x\ge0$、$\frac{2x}{1-x^2}\ge2x$、均值不等式等），再放。

**不要这样写**：「构造函数 $f(x)=(1+x)\ln^2(1+x)-x^2$，求得 $f''(x)<0$，故结论成立。」——读者看不出为什么是这个函数、为什么要求二阶导。

**应当这样写**：见下方示例。

### 示例：把一道短题按六步骨架写开

题目：$x>0$ 时，$(1+x)\ln^2(1+x)<x^2$。

**考场分析**（直接构造型，两行）

1. 题面长相：对数平方乘一个因子与幂函数比大小，两端相减型，无参数、无分式。
2. 倒推链：证差 $<0$ ⟸ 证差函数在 $x>0$ 递减 ⟸ 证一阶导 $\le0$ ⟸ 证二阶导 $<0$；靠 $f(0)=0$、$f'(0)=0$ 两级端点值兜住符号。

**解题步骤**

不等式两端相减，令 $f(x)=(1+x)\ln^2(1+x)-x^2$，其中 $x\ge0$。

算端点值：$f(0)=0$。

要证 $x>0$ 时 $f(x)<0=f(0)$，只需证 $f$ 在 $x\ge0$ 上递减，即只需证 $f'(x)\le0$。

$f'(x)=\ln^2(1+x)+2\ln(1+x)-2x$，且 $f'(0)=0$。

一阶导的符号仍判不出，再求二阶导：

$f''(x)=\frac{2\ln(1+x)}{1+x}+\frac{2}{1+x}-2=\frac{2}{1+x}(\ln(1+x)-x)$

由已知不等式 $\ln(1+x)<x$（$x>0$），得 $f''(x)<0$。

回推：$f''(x)<0$ 说明 $f'$ 递减，配合 $f'(0)=0$ 得 $x>0$ 时 $f'(x)<0$；故 $f$ 递减，配合 $f(0)=0$ 得 $x>0$ 时 $f(x)<0$。

**答案** $\boxed{(1+x)\ln^2(1+x)<x^2}$

## 五、与已学结论挂钩

推导中一旦归结到已有结论，要显式写出它的名字或编号，例如「归结为 $\ln^2(1+x)<\frac{x^2}{1+x}$，即本章例题 1」。这类归结是本章题目的常见收尾方式，读者需要知道用的是哪条结论，而不是凭空出现一个不等式。

## 六、配套规则

1. **要考场状态，不要自检**（用户明确要求，务必遵守）：
  - 解题就是**考场上考生现场作答**的样子：读题 → 想明白走哪条路 → 一次写到底 → 收尾。推完即止，写出来的是什么就是什么。
  - 解答正文中**不出现**「自检 / 自查 / 验算 / 复核 / 核对 / 回代验证」这类环节，也**不写**「取 $x=0.01$，数值 $\approx\dots$ ✓」这类事后数值核对。这类内容一律省略，不写进回答。
  - 允许的判断只发生在两处：**落笔前**（本题怎么归类、走哪条路、哪里有坑——写在「考场分析」里），以及**收尾时**看结论是否就是题设所要求的那个形式。这属于正常解题思维，不算自检。
  - 公式排版的正确性由第 4 条的规范保证，不再单列成「发出前检查一遍」的动作。

2. **信息不全先问清**：缺图、缺条件、缺选项时，一次性列出需要确认的点；能合理推断的写明「我按 …… 理解，如需更正请指出」，边答边确认，不因个别信息缺失整体卡住。

3. **禁止滥用中间记号代值**（用户明确要求，务必遵守）：
  - 推导过程中**不要**引入 $u$、$v$、$A$、$B$ 之类记号去替代 $x-a$、$b-x$、$f(c)$ 等表达式。直接按原始表达式写、按原始表达式算，例如写「记 $x-a$ 与 $b-x$」，而不是「令 $u=x-a,\ v=b-x$」。
  - 原因：代号的写法只对书写者省事，读的人必须来回对照，反而增加负担。
  - **仅两种情况允许使用**：① 该表达式在本步中确实很长、反复出现，直接写会严重妨碍阅读；② 换元本身就是解题手段（如 $t=\frac{1}{x}$、$t=\tan\frac{x}{2}$ 这类真正的变量替换）。
  - 即使允许使用，也必须在首次出现处写明「令 $u=\dots$」，并在结论处换回原变量。

4. **公式排版规范**（防 KaTeX/MathJax 渲染报错）：
  - `$…$`、`$$…$$` 内**禁止中文**和①②圈码，「原式」「所以」等字样写在公式外；
  - 每条 `$$…$$` 必须**单行**；长推导拆成多个单行显示式加步骤文字，不用 `aligned`/`cases`/`\\` 换行；
  - 衔接词（于是 / 即 / 故）写在公式外，不用 `\Longrightarrow` 之类箭头连接多行；
  - 不用 `\underbrace`/`\overbrace`，`\bigl` 等一律写成普通括号，行内式用 `\frac`；
  - `\boxed{}` 内只放纯结果；**引用块内不放显示公式**。
