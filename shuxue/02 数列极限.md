# 02 数列极限

> **章节定位**：数列极限是高等数学上册的基石，考研数一/二/三每年必考——选择题常考收敛数列的性质（唯一性、有界性、保号性）与极限存在准则；解答题常考递推数列"单调有界→解方程"求极限、定积分定义求和式极限、夹逼放缩等，分值约 4~10 分，并是后续级数、反常积分、幂级数求和的基础。

## 一、知识框架

- 数列极限的概念
  - ε-N 定义：$\forall\varepsilon>0,\ \exists N\in\mathbb N_+$，当 $n>N$ 时有 $|x_n-a|<\varepsilon$（重点理解"任意给定误差 $\varepsilon$，都能找到足够大的 $N$"的含义）
  - 几何意义与定义的否定形式
  - 收敛与发散（极限不存在≠极限为无穷大）
- 收敛数列的性质
  - 唯一性（极限若存在必唯一）
  - 有界性（收敛 ⇒ 有界；逆否：无界 ⇒ 发散）
  - 保号性（极限正 ⇒ 从某项起通项恒正，及推论）
  - 四则运算法则
  - 子列：收敛数列的任一子列收敛于同一极限（逆否：存在两个子列极限不同 ⇒ 原数列发散）
- 极限存在准则
  - 夹逼准则（两边夹，放缩技巧）
  - 单调有界准则（单调递增 + 上界，或单调递减 + 下界 ⇒ 收敛）
- 极限的计算方法
  - 递推数列求极限：先证"单调有界 → 极限存在"，再对递推式两边取极限解方程
  - 定积分定义：$\dfrac1n\sum_{k=1}^n f\Big(\dfrac kn\Big)\to\int_0^1 f(x)\,dx$（重点）
  - 海涅定理 / 归结原则（数列极限与函数极限互推）
  - 函数化处理：等价无穷小、两个重要极限、洛必达法则（借助函数化）
  - 常见放缩技巧：n 项和、n 次根号、连乘式（取对数）

## 二、常考题型

### 题型 1：ε-N 定义与收敛数列的性质

- **识别特征**：题目要求"用定义证明 $\lim x_n=a$"；或考查唯一性、有界性、保号性、子列性质的判断（常见于选择题）。
- **解题套路**：
  1. 写出 $|x_n-a|$，并**适当放大**成只含 $n$ 的简单式子，令其 $<\varepsilon$；
  2. 解出 $n>N(\varepsilon)$，取 $N$（可带取整号，不必最小）；
  3. 按定义叙述"$\forall\varepsilon>0,\ \exists N$，当 $n>N$ 时恒有 $|x_n-a|<\varepsilon$"。
- **典型例题**：
  - 例 1：用定义证明 $\displaystyle\lim_{n\to\infty}\frac{n}{n+1}=1$。
    解：$|x_n-1|=\Big|\dfrac{n}{n+1}-1\Big|=\dfrac{1}{n+1}$。任给 $\varepsilon>0$，要使 $\dfrac{1}{n+1}<\varepsilon$，只需 $n>\dfrac1\varepsilon-1$，取 $N=\Big[\dfrac1\varepsilon-1\Big]$（或取 $N>\dfrac1\varepsilon$），则当 $n>N$ 时恒有 $|x_n-1|<\varepsilon$，故 $\displaystyle\lim_{n\to\infty}\frac n{n+1}=1$。
  - 例 2（性质判断）：下列说法正确的是（　）。
    A. 有界数列必收敛　B. 收敛数列必有界　C. 无界数列必发散　D. 单调数列必收敛
    答案：**B、C**。（有界不一定收敛，如 $(-1)^n$ 有界但发散；单调不一定收敛，如 $x_n=n$ 单调递增但发散。）
- **易错点**：
  1. 定义中 $N$ 只需"存在"，可与 $\varepsilon$ 有关，方向是 $n>N$（不是 $n\ge N$ 与 $\varepsilon$ 无关）；
  2. 收敛 ⇒ 有界，但**逆命题不成立**（$(-1)^n$ 是经典反例）；无界必发散。

### 题型 2：夹逼准则求极限（n 项和放缩）

- **识别特征**：通项是 n 项**之和**（或积），且各项结构"差不多"，可对分母/项数统一放大缩小。
- **解题套路**：
  1. 找到通项的**统一上界与下界**（把分母换成最大/最小、把项数放大/缩小）；
  2. 两侧分别化简求和，证明两侧极限**相等**（同为常数 $L$）；
  3. 由夹逼准则得原极限 $=L$。
- **典型例题**：
  - 例 1：求 $\displaystyle\lim_{n\to\infty}\Big(\frac{1}{n^2+n+1}+\frac{2}{n^2+n+2}+\cdots+\frac{n}{n^2+n+n}\Big)$。
    解：对每一项有 $\dfrac{k}{n^2+n+n}\le\dfrac{k}{n^2+n+k}\le\dfrac{k}{n^2+n+1}$，故
    $$\frac{1+2+\cdots+n}{n^2+2n}\le S_n\le\frac{1+2+\cdots+n}{n^2+n+1},$$
    即 $\dfrac{n(n+1)/2}{n^2+2n}\le S_n\le\dfrac{n(n+1)/2}{n^2+n+1}$。两端极限均为 $\dfrac12$，故 $\lim S_n=\dfrac12$。
  - 例 2：求 $\displaystyle\lim_{n\to\infty}\sqrt[n]{1+2^n+3^n}$。
    解：$3=\sqrt[n]{3^n}<\sqrt[n]{1+2^n+3^n}<\sqrt[n]{3\cdot3^n}=3\sqrt[n]{3}\to3$，故原极限 $=3$。
- **易错点**：
  1. 放缩后两侧极限必须**相等**，否则夹逼失效（放缩太松）；
  2. n 项和要先**求和公式化**（等差/等比）再取极限，不能逐项取极限。

### 题型 3：单调有界准则（证明递推数列收敛的核心）

- **识别特征**：给定递推数列 $x_{n+1}=f(x_n)$，要求证明"极限存在"（或先证存在再求值）。
- **解题套路**：
  1. **证单调**：作差 $x_{n+1}-x_n$ 或作比 $\dfrac{x_{n+1}}{x_n}$（正项数列），或数学归纳法；
  2. **证有界**：归纳法给出上界（递增时）或下界（递减时）；
  3. 由单调有界准则断言极限存在，设 $\lim x_n=a$；
  4. 对递推式两边取极限得 $a=f(a)$，解方程并**舍去不合题意根**。
- **典型例题**：
  - 例 1：设 $x_1=\sqrt2$，$x_{n+1}=\sqrt{2+x_n}$，证明 $\{x_n\}$ 收敛并求极限。
    解：① 有界性：$x_1=\sqrt2<2$；若 $x_n<2$，则 $x_{n+1}=\sqrt{2+x_n}<\sqrt4=2$，归纳得 $x_n<2$。
    ② 单调性：$x_{n+1}-x_n=\sqrt{2+x_n}-x_n=\dfrac{2+x_n-x_n^2}{\sqrt{2+x_n}+x_n}=\dfrac{(2-x_n)(1+x_n)}{\sqrt{2+x_n}+x_n}>0$（因 $x_n<2$），故单调递增。
    ③ 设 $\lim x_n=a$，对 $x_{n+1}=\sqrt{2+x_n}$ 取极限得 $a=\sqrt{2+a}$，即 $a^2-a-2=0$，解得 $a=2$（舍 $-1$）。故 $\displaystyle\lim_{n\to\infty}x_n=2$。
  - 例 2：设 $x_1=1$，$x_{n+1}=\dfrac12\Big(x_n+\dfrac2{x_n}\Big)$，证明收敛并求极限。
    解：① 由均值不等式 $x_{n+1}=\dfrac12\Big(x_n+\dfrac2{x_n}\Big)\ge\sqrt2$（$n\ge2$ 时），即有下界。
    ② 单调性：$x_{n+1}-x_n=\dfrac12\Big(\dfrac2{x_n}-x_n\Big)=\dfrac{2-x_n^2}{2x_n}\le0$，故单调递减。
    ③ 设 $\lim x_n=a$，则 $a=\dfrac12\Big(a+\dfrac2a\Big)$，即 $a^2=2$，$a=\sqrt2$（舍负）。此即求 $\sqrt2$ 的牛顿迭代。
- **易错点**：
  1. 不能跳过"证单调有界"直接解方程——极限可能不存在，解出的 $a$ 无意义；
  2. 单调性与有界性的证明方向要自洽：递增配"上界"、递减配"下界"。

### 题型 4：递推数列求极限（先证存在、再解方程）

- **识别特征**：给出初值 $x_1$ 及递推关系 $x_{n+1}=f(x_n)$，求 $\lim x_n$；常与单调有界准则合并考查。
- **解题套路**：
  1. 先用单调有界准则（或压缩映射、奇偶子列）**证明极限存在**；
  2. 设 $\lim x_n=a$，对 $x_{n+1}=f(x_n)$ 两边取极限得 $a=f(a)$；
  3. 解方程，按初值范围、正负性**舍去多余根**。
- **典型例题**：
  - 例 1：设 $x_1=2$，$x_{n+1}=\sqrt{2x_n+3}$，求 $\lim x_n$。
    解：先归纳 $1<x_n<3$：$x_1=2\in(1,3)$；若 $x_n\in(1,3)$，则 $2x_n+3\in(5,9)$，$x_{n+1}=\sqrt{2x_n+3}\in(\sqrt5,3)\subset(1,3)$。
    单调性：$x_{n+1}-x_n=\sqrt{2x_n+3}-x_n=\dfrac{(3-x_n)(x_n+1)}{\sqrt{2x_n+3}+x_n}>0$（因 $x_n<3$），故递增。
    设 $\lim x_n=a$，则 $a=\sqrt{2a+3}$，即 $a^2-2a-3=0$，解得 $a=3$（舍 $-1$）。故 $\displaystyle\lim_{n\to\infty}x_n=3$。
  - 例 2：设 $x_1=1$，$x_{n+1}=\dfrac{x_n+2}{x_n+1}$，求 $\lim x_n$。
    解：由 $x_{n+1}=1+\dfrac1{x_n+1}$ 知 $x_n>0$，且 $x_n\in(1,2)$（$n\ge2$）。设极限为 $a$，则 $a=\dfrac{a+2}{a+1}$，即 $a(a+1)=a+2$，得 $a^2=2$，$a=\sqrt2$。
    （说明：其单调性可借助 $x_n-\sqrt2$ 正负交替、奇偶子列分别单调有界来证明；此处核心是"先证存在，再解方程"。）
- **易错点**：
  1. 解出的方程可能有多根，须结合初值与有界范围**舍去不合题意的根**（常见舍负根）；
  2. "先证存在、再取极限"的顺序不可颠倒——即使方程只有一根，也不代表极限一定存在。

### 题型 5：定积分定义求数列极限（重点）

- **识别特征**：通项形如 $\dfrac1n\sum_{k=1}^n f\Big(\dfrac kn\Big)$，即"$\frac1n\times$求和"，且 $f$ 的自变量恰为 $\dfrac kn$。
- **解题套路**：
  1. 把通项化成 $\dfrac1n\sum_{k=1}^n f\Big(\dfrac kn\Big)$ 标准形（提取 $\dfrac1n$，凑出 $\dfrac kn$）；
  2. 令 $\dfrac kn\to x$，$\dfrac1n\to dx$，写成 $\int_0^1 f(x)\,dx$；
  3. 算出定积分即得极限。
- **典型例题**：
  - 例 1：求 $\displaystyle\lim_{n\to\infty}\Big(\frac{1}{n+1}+\frac{1}{n+2}+\cdots+\frac{1}{n+n}\Big)$。
    解：通项 $=\dfrac1n\sum_{k=1}^n\dfrac{1}{1+\frac kn}\to\int_0^1\dfrac{dx}{1+x}=\ln(1+x)\Big|_0^1=\ln2$。
  - 例 2：求 $\displaystyle\lim_{n\to\infty}\Big(\frac{1}{\sqrt{n^2+1^2}}+\frac{1}{\sqrt{n^2+2^2}}+\cdots+\frac{1}{\sqrt{n^2+n^2}}\Big)$。
    解：通项 $=\dfrac1n\sum_{k=1}^n\dfrac{1}{\sqrt{1+\big(\frac kn\big)^2}}\to\int_0^1\dfrac{dx}{\sqrt{1+x^2}}=\ln\Big(x+\sqrt{1+x^2}\Big)\Big|_0^1=\ln(1+\sqrt2)$。
- **易错点**：
  1. 必须出现 $\dfrac1n$ 与 $\dfrac kn$ 的**配套结构**；区间若不是 $[0,1]$，要按 $\dfrac{b-a}{n}\sum_{k=1}^n f\Big(a+\frac{k(b-a)}n\Big)\to\int_a^b f(x)\,dx$ 处理；
  2. 求和范围与 $\frac kn$ 对应关系要一致（$\sum_{k=1}^n$ 对应 $x=\frac kn\in(0,1]$）。

### 题型 6：海涅定理 / 归结原则

- **识别特征**：需要把"函数极限"与"数列极限"互推；或证明函数极限不存在（构造两个数列）。
- **解题套路**：
  1. 正向：$\lim_{x\to a}f(x)=A\Rightarrow$ 对一切 $x_n\to a$（$x_n\ne a$）有 $f(x_n)\to A$；
  2. 逆向：若所有满足 $x_n\to a$ 的数列都使 $f(x_n)\to$ 同一值，则函数极限存在；
  3. 反例：找两条 $x_n,x_n'\to a$ 但 $f(x_n),f(x_n')$ 极限不同，则 $\lim_{x\to a}f(x)$ 不存在。
- **典型例题**：
  - 例 1：求 $\displaystyle\lim_{n\to\infty} n\ln\Big(1+\frac1n\Big)$。
    解：令 $t=\dfrac1n\to0^+$，由海涅定理 $\displaystyle\lim_{n\to\infty}n\ln\Big(1+\frac1n\Big)=\lim_{t\to0^+}\frac{\ln(1+t)}t=\lim_{t\to0^+}\frac tt=1$。
  - 例 2：证明 $\displaystyle\lim_{x\to0}\sin\frac1x$ 不存在。
    解：取 $x_n=\dfrac1{2n\pi}\to0$，则 $\sin\dfrac1{x_n}=\sin(2n\pi)=0\to0$；再取 $x_n'=\dfrac1{2n\pi+\frac\pi2}\to0$，则 $\sin\dfrac1{x_n'}=1\to1$。两数列都趋于 0，但对应函数值极限不同，故 $\displaystyle\lim_{x\to0}\sin\frac1x$ 不存在。
- **易错点**：
  1. 要求 $x_n\ne a$（避免取到 $f$ 在 $a$ 处无定义的情形）；
  2. 只能由"函数极限存在"推"任意数列极限相同"，不能由**单个**数列极限反推函数极限存在。

### 题型 7：n 次根号、连乘式等放缩技巧

- **识别特征**：通项含 $\sqrt[n]{\cdots}$、$n!$、连乘式，或 n 项积。
- **解题套路**：
  1. n 次根号型：夹出主导项 $\sqrt[n]{a_1^n+\cdots+a_m^n}\to\max a_i$；
  2. 连乘式：取对数 $\ln$（化积为和），再用定积分定义或夹逼，最后还原；
  3. 含阶乘：与 $\dfrac1n$、$\dfrac1{n^k}$ 比较夹逼，或利用 $\dfrac{n!}{n^n}\le\dfrac1n$。
- **典型例题**：
  - 例 1：求 $\displaystyle\lim_{n\to\infty}\sqrt[n]{3^n+5^n}$。
    解：$5=\sqrt[n]{5^n}\le\sqrt[n]{3^n+5^n}\le\sqrt[n]{2\cdot5^n}=5\sqrt[n]{2}\to5$，故极限 $=5$。
  - 例 2：求 $\displaystyle\lim_{n\to\infty}\frac{n!}{n^n}$。
    解：$0<\dfrac{n!}{n^n}=\dfrac1n\cdot\dfrac2n\cdots\dfrac nn\le\dfrac1n\cdot1\cdots1=\dfrac1n\to0$，由夹逼得极限 $=0$。
- **易错点**：
  1. $\sqrt[n]{a^n+b^n}$ **不能**拆成 $\sqrt[n]{a^n}+\sqrt[n]{b^n}$；
  2. 连乘式取对数后勿忘最后再取指数还原。

### 题型 8：函数化处理（等价无穷小、重要极限、洛必达）

- **识别特征**：通项含 $\frac1n$ 的无穷小因子或幂指结构，直接套数列极限公式困难。
- **解题套路**：
  1. 令 $t=\dfrac1n$（或 $x=n$），把数列极限转化为函数极限（海涅定理保证等价）；
  2. 用等价无穷小替换、重要极限、洛必达法则计算；
  3. 返回数列极限。
- **典型例题**：
  - 例 1：求 $\displaystyle\lim_{n\to\infty}\Big(1+\frac1n\Big)^n$。
    解：这是重要极限，$\displaystyle\lim_{n\to\infty}\Big(1+\frac1n\Big)^n=e$。
  - 例 2：求 $\displaystyle\lim_{n\to\infty} n^2\Big(1-\cos\frac1n\Big)$。
    解：由 $1-\cos x\sim\dfrac{x^2}{2}$（$x\to0$），原式 $=\lim n^2\cdot\dfrac12\Big(\dfrac1n\Big)^2=\dfrac12$。
- **易错点**：
  1. 洛必达只能用于函数（连续变量），不能对离散变量 $n$ 直接求导，须先函数化；
  2. 等价无穷小替换只在**乘除因式**中使用，加减中慎用。

| 技巧/结论 | 适用场景 | 记忆要点 |
|---|---|---|
| $\lim_{n\to\infty}\sqrt[n]{n}=1$ | n 次根号放缩 | 用 $e^{\frac{\ln n}{n}}$ 或二项式展开 |
| $\lim_{n\to\infty}\sqrt[n]{a}=1$（$a>0$） | 常数开 n 次方 | 直接为 1 |
| $\lim_{n\to\infty}q^n=0$（$|q|<1$） | 等比通项 | 公比绝对值小于 1 |
| $\lim_{n\to\infty}\Big(1+\frac1n\Big)^n=e$ | 重要极限 | $1^\infty$ 型，勿得 1 |
| $\lim_{n\to\infty}\dfrac{n^\alpha}{a^n}=0$（$a>1$） | 幂指比较 | 指数增长快于幂 |
| $\lim_{n\to\infty}\dfrac{a^n}{n!}=0$、$\dfrac{n!}{n^n}=0$ | 阶乘比较 | 阶乘与幂/指数比较 |
| $\dfrac1n\sum_{k=1}^n f\Big(\frac kn\Big)\to\int_0^1 f(x)\,dx$ | 定积分定义 | 凑 $\frac1n$ 与 $\frac kn$ |
| 单调有界准则 | 递推数列证存在 | 单调 + 有界 ⇒ 收敛 |
| 夹逼准则 | n 项和/积 | 两侧极限要相等 |
| 海涅定理 | 数列 ⇆ 函数极限互推 | 要求 $x_n\to a$ 且 $x_n\ne a$ |
| 收敛 ⇒ 有界 | 判断发散 | 逆否：无界必发散 |
| 收敛数列保号性 | 判断极限正负 | 极限与通项同号 |

## 四、易错点清单

- 有界数列不一定收敛（如 $(-1)^n$）；无界数列一定发散。
- 单调数列不一定收敛（如 $x_n=n$、$x_n=n^2$），须再验证有界。
- 递推数列求极限时，不能未经"证收敛"就直接对递推式取极限解方程。
- 单调有界准则中"单调"与"有界"**缺一不可**，且递增配"上界"、递减配"下界"。
- 夹逼放缩后两侧极限若不相等，说明放缩过松，须调整放缩。
- 定积分定义要求严格的 $\dfrac1n\sum f\Big(\frac kn\Big)$ 结构，缺 $\frac1n$ 或自变量不对都不能直接用。
- 洛必达法则只能用于函数，不能对离散变量 $n$ 直接求导。
- 海涅定理要求 $x_n\to a$ 且 $x_n\ne a$，且只能由"函数极限存在"推"任意数列极限相同"。
- $\sqrt[n]{a^n+b^n}$ 不能拆成 $\sqrt[n]{a^n}+\sqrt[n]{b^n}$。
- 等价无穷小替换仅限乘除因式，加减中直接替换可能出错。
- 用"单调有界"求极限时，方程多根要按初值与范围舍根（常舍负根）。
- 收敛数列的四则运算要求各极限都存在，且除法分母极限非零。
