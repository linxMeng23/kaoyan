# 03 连续性 间断点 渐近线

> **章节定位**：本章是高等数学上册承上启下的核心基础章，向上承接极限，向下衔接导数（连续是可导的必要条件）。考研数一/二/三通用重点，常见考法有：判断函数在某点的连续性、求间断点并分类、利用连续性求参数、用零点定理证明方程根的存在性、求曲线的渐近线，多出现在选择、填空与证明题中。

## 一、知识框架

- 函数连续的定义
  - 在某点连续的三条件：$f(x_0)$ 有定义、$\lim_{x\to x_0}f(x)$ 存在、$\lim_{x\to x_0}f(x)=f(x_0)$
  - 左连续：$\lim_{x\to x_0^-}f(x)=f(x_0)$
  - 右连续：$\lim_{x\to x_0^+}f(x)=f(x_0)$
  - 连续 $\iff$ 左连续且右连续
- 间断点的分类
  - 第一类间断点（左右极限都存在）
    - 可去间断点：左右极限相等但 $\neq f(x_0)$ 或 $f(x_0)$ 无定义
    - 跳跃间断点：左右极限都存在但不相等
  - 第二类间断点（左右极限至少有一个不存在）
    - 无穷间断点：至少一侧极限为 $\infty$
    - 振荡间断点：极限因振荡而不存在（如 $\sin\frac1x$）
- 连续函数的运算性质
  - 连续函数的和、差、积、商（分母不为零）仍连续
  - 复合函数：外函数连续、内函数连续 $\Rightarrow$ 复合函数连续
  - 初等函数在其定义区间内处处连续
- 闭区间上连续函数的性质
  - 最值定理：$f\in C[a,b]$ 必有最大值与最小值
  - 介值定理：可取到介于最大值与最小值之间的任何值
  - 零点定理：$f\in C[a,b]$ 且 $f(a)f(b)<0$，则存在 $\xi\in(a,b)$ 使 $f(\xi)=0$（**重点**，用于证根的存在性）
- 渐近线
  - 水平渐近线：$\lim_{x\to\infty}f(x)=b$
  - 垂直渐近线：$\lim_{x\to x_0}f(x)=\infty$
  - 斜渐近线：$y=kx+b$，其中 $k=\lim_{x\to\infty}\dfrac{f(x)}{x}$，$b=\lim_{x\to\infty}[f(x)-kx]$

## 二、常考题型

### 题型 1：函数连续性的定义与判断

- **识别特征**：给出函数（多为分段函数）或含 $x_0$ 的函数，问在 $x_0$ 处是否连续，或补充定义使其连续。
- **解题套路**：
  1. 检查 $f(x_0)$ 是否有定义；
  2. 求 $\lim_{x\to x_0}f(x)$（分段函数要分别求左、右极限）；
  3. 比较极限值与函数值：三条件同时成立则连续，否则不连续。
- **典型例题**：讨论 $f(x)=\begin{cases}x^2\sin\dfrac1x,&x\neq0\\0,&x=0\end{cases}$ 在 $x=0$ 处的连续性。
  **解**：因 $\left|x^2\sin\dfrac1x\right|\le x^2\to0$，故 $\lim_{x\to0}x^2\sin\dfrac1x=0=f(0)$，所以 $f(x)$ 在 $x=0$ 处连续。
- **易错点**：
  - 只算极限不看"是否有定义、是否等于函数值"，漏掉条件；
  - 分段函数分界点必须左右极限都算，不能只算单侧。

### 题型 2：利用连续性求参数

- **识别特征**：分段函数在分界点处连续，求待定常数（常含一个或两个参数）。
- **解题套路**：
  1. 写出"左极限 = 右极限 = 函数值"的方程；
  2. 若极限为 $\dfrac00$ 型，先让分子（或使极限存在的部分）满足必要条件再求极限；
  3. 解方程得到待定常数。
- **典型例题**：设 $f(x)=\begin{cases}\dfrac{x^2+ax+b}{x-1},&x\neq1\\3,&x=1\end{cases}$ 在 $x=1$ 处连续，求 $a,b$。
  **解**：要使 $\lim_{x\to1}\dfrac{x^2+ax+b}{x-1}$ 存在，必须 $x^2+ax+b\big|_{x=1}=0$，即 $1+a+b=0$，从而 $x^2+ax+b=(x-1)(x+1+a)$。于是 $\lim_{x\to1}f(x)=\lim_{x\to1}(x+1+a)=2+a$。由连续性得 $2+a=3$，故 $a=1$，再由 $1+a+b=0$ 得 $b=-2$。
- **易错点**：
  - 忘记"极限存在"对分子为零的隐含要求，直接代入得不出方程；
  - 参数不止一个时，方程可能不唯一，要凑齐所有条件。

### 题型 3：间断点的分类与判别方法

- **识别特征**：给出间断点（或候选点），要求判断其类型（可去 / 跳跃 / 无穷 / 振荡）。
- **解题套路**：
  1. 求 $\lim_{x\to x_0^-}f(x)$ 与 $\lim_{x\to x_0^+}f(x)$；
  2. 左右极限**都存在** $\Rightarrow$ 第一类：相等为**可去**，不等为**跳跃**；
  3. 至少一侧极限**不存在** $\Rightarrow$ 第二类：趋于 $\infty$ 为**无穷**，振荡不定为**振荡**。
- **典型例题**：判断 $f(x)=\dfrac{x^2-1}{x^2-3x+2}$ 的间断点类型。
  **解**：$f(x)=\dfrac{(x-1)(x+1)}{(x-1)(x-2)}$，间断点为 $x=1,2$。$\lim_{x\to1}f(x)=\lim_{x\to1}\dfrac{x+1}{x-2}=-2$（存在），但 $f(1)$ 无定义，故 $x=1$ 为**可去间断点**；$\lim_{x\to2}f(x)=\infty$，故 $x=2$ 为**无穷间断点**。
- **易错点**：
  - 把"极限存在但无定义/不等"与"连续"混淆；
  - 第二类不只有无穷，还要考虑振荡间断点。

### 题型 4：求函数的间断点并分类（典型函数）

- **识别特征**：给出一个具体函数（含 $e^{1/x}$、$\dfrac{x}{|x|}$、$\sin\dfrac1x$、分段函数等），要求找出全部间断点并分类。
- **解题套路**：
  1. 先找所有"无定义点"（分母零点、对数真数零点、分段分界点等）作为候选间断点；
  2. 对每个候选点分别求左右极限；
  3. 按题型 3 的判别标准逐点分类。
- **典型例题**：求下列函数的间断点并分类。
  （1）$f(x)=\dfrac{e^{1/x}+1}{e^{1/x}-1}$，$x=0$：$\lim_{x\to0^+}f(x)=\lim_{x\to0^+}\dfrac{e^{1/x}+1}{e^{1/x}-1}=1$，$\lim_{x\to0^-}f(x)=\dfrac{0+1}{0-1}=-1$，左右极限存在不等，为**跳跃间断点**。
  （2）$f(x)=\dfrac{x}{|x|}\ (x\neq0)$，$x=0$：右极限 $1$，左极限 $-1$，为**跳跃间断点**（即符号函数 $\mathrm{sgn}\,x$）。
  （3）$f(x)=\dfrac{\sin x}{x}\ (x\neq0)$，$x=0$：$\lim_{x\to0}\dfrac{\sin x}{x}=1$ 存在但 $f(0)$ 无定义，为**可去间断点**，补充 $f(0)=1$ 后连续。
  （4）$f(x)=\sin\dfrac1x$，$x=0$：极限因振荡而不存在，为**第二类振荡间断点**。
  （5）$f(x)=\dfrac1x$，$x=0$：$\lim_{x\to0}\dfrac1x=\infty$，为**无穷间断点**。
  （6）$f(x)=\begin{cases}x^2,&x\le0\\1,&x>0\end{cases}$，$x=0$：$\lim_{x\to0^-}f(x)=0$，$\lim_{x\to0^+}f(x)=1$，不等，为**跳跃间断点**。
- **易错点**：
  - $e^{1/x}$ 在 $x=0$ 处左右极限不同（左 $0$、右 $+\infty$），勿当作无穷间断点处理；
  - 漏找无定义点：要系统排查分母、对数、正切等所有使函数无定义的位置。

### 题型 5：零点定理证明根的存在性

- **识别特征**：证明方程 $f(x)=0$ 在某区间内至少有一个实根，或证明存在 $\xi$ 使 $F(\xi)=0$。
- **解题套路**：
  1. 构造辅助函数 $F(x)$，使结论化为 $F(\xi)=0$；
  2. 验证 $F(x)$ 在闭区间 $[a,b]$ 上连续；
  3. 验证 $F(a)F(b)<0$（或 $F(a)F(b)\le0$ 再讨论端点为零的情形）；
  4. 由零点定理得存在 $\xi\in(a,b)$ 使 $F(\xi)=0$。
- **典型例题**：证明方程 $x^3-4x^2+1=0$ 在 $(0,1)$ 内至少有一个实根。
  **解**：令 $f(x)=x^3-4x^2+1$，在 $[0,1]$ 上连续，且 $f(0)=1>0$，$f(1)=1-4+1=-2<0$，故 $f(0)f(1)<0$，由零点定理存在 $\xi\in(0,1)$ 使 $f(\xi)=0$，即原方程在 $(0,1)$ 内至少有一个实根。
- **易错点**：
  - 忘记验证"闭区间连续"与"端点异号"两个前提；
  - 结论是"至少一个根"，不能误认为唯一（唯一性需结合单调性）。

### 题型 6：求水平渐近线与垂直渐近线

- **识别特征**：给出函数解析式，求水平渐近线 $y=b$ 和垂直渐近线 $x=x_0$。
- **解题套路**：
  1. 水平：分别算 $\lim_{x\to+\infty}f(x)$ 与 $\lim_{x\to-\infty}f(x)$，若存在有限值 $b$，则 $y=b$ 为水平渐近线（两侧可能不同）；
  2. 垂直：找函数无定义点 $x_0$，验证 $\lim_{x\to x_0}f(x)=\infty$（或单侧为 $\infty$），则 $x=x_0$ 为垂直渐近线。
- **典型例题**：求 $y=\dfrac{3x^2+2}{2x^2-1}$ 的渐近线。
  **解**：$\lim_{x\to\infty}\dfrac{3x^2+2}{2x^2-1}=\dfrac32$，故水平渐近线为 $y=\dfrac32$；无定义点为 $x=\pm\dfrac{1}{\sqrt2}$，且分母趋于 $0$、分子不为 $0$，故 $\lim_{x\to\pm\frac{1}{\sqrt2}}y=\infty$，垂直渐近线为 $x=\dfrac{1}{\sqrt2}$ 与 $x=-\dfrac{1}{\sqrt2}$。
- **易错点**：
  - 水平渐近线必须 $x\to+\infty$、$x\to-\infty$ 分别看（如 $y=\arctan x$ 有两条水平渐近线 $y=\pm\dfrac\pi2$）；
  - 无定义点只是候选，需验证极限为 $\infty$（若极限有限则是可去间断，无垂直渐近线）。

### 题型 7：求斜渐近线

- **识别特征**：当 $\lim_{x\to\infty}f(x)=\infty$（无水平渐近线）时，求斜渐近线 $y=kx+b$。
- **解题套路**：
  1. 求 $k=\lim_{x\to\infty}\dfrac{f(x)}{x}$（$k$ 存在且为非零有限数）；
  2. 求 $b=\lim_{x\to\infty}[f(x)-kx]$（$b$ 存在有限）；
  3. 写出斜渐近线 $y=kx+b$。注意 $x\to+\infty$ 与 $x\to-\infty$ 应分别考虑；若 $k=0$，则退化为水平渐近线。
- **典型例题**：求曲线 $y=\dfrac{x^2+1}{x-1}$ 的渐近线。
  **解**：垂直渐近线：$\lim_{x\to1}\dfrac{x^2+1}{x-1}=\infty$，故 $x=1$ 为垂直渐近线。水平：$\lim_{x\to\infty}\dfrac{x^2+1}{x-1}=\infty$，无水平渐近线。斜：$k=\lim_{x\to\infty}\dfrac{f(x)}{x}=\lim_{x\to\infty}\dfrac{x^2+1}{x(x-1)}=1$；$b=\lim_{x\to\infty}[f(x)-x]=\lim_{x\to\infty}\left[\dfrac{x^2+1}{x-1}-x\right]=\lim_{x\to\infty}\dfrac{x+1}{x-1}=1$。故斜渐近线为 $y=x+1$。
- **易错点**：
  - 必须先求 $k$，若 $k$ 不存在（或为 $\infty$）则无斜渐近线；
  - 求 $b$ 时忘记减去 $kx$，导致 $b$ 算错；
  - $k=0$ 时是水平渐近线，不要写成"斜渐近线 $y=b$"。
  - 渐近线条件可反向考：给出"$\lim_{x\to+\infty}\left[f(x)-kx-b\right]=0$ 求参数"，就是已知渐近线反解 $k,b$（见例 2）；随后还能追问"趋近渐近线的速度"（需展开高一阶）。
- **典型例题（续）**：
  - 例 2（渐近线定义式反求参数）：设 $\displaystyle\lim_{x\to+\infty}\left(\sqrt{ax^2+2bx+c}-\alpha x-\beta\right)=0$（$a>0$），求 $\alpha,\beta$ 及 $\displaystyle\lim_{x\to+\infty}x\left(\sqrt{ax^2+2bx+c}-\alpha x-\beta\right)$。
    - 解（一次有理化＋逐层清零）：对原差保留符号直接有理化：$\sqrt{ax^2+2bx+c}-\alpha x-\beta=\dfrac{(a-\alpha^{2})x^{2}+(2b-2\alpha\beta)x+(c-\beta^{2})}{\sqrt{ax^2+2bx+c}+\alpha x+\beta}$；分母相对 $x$ 是一次量（首项 $\sqrt a+\alpha$），要整个式子趋于零，分子的二次、一次项系数必须都为零（否则分别对应发散、非零常数）；
    - 清零定参：$a-\alpha^{2}=0$ 且 $2b-2\alpha\beta=0$，得 $\alpha=\pm\sqrt a$，$\beta=b/\alpha$；回代原差筛选：$\alpha=-\sqrt a$ 时原差主部 $(\sqrt a+\sqrt a)x\to+\infty$，矛盾舍去，故 $\alpha=\sqrt a$，$\beta=b/\sqrt a$；
    - 读速度极限：清零后分子恰剩常数 $c-\beta^{2}=c-\tfrac{b^{2}}a$，分母 $\sim2\sqrt a\,x$，故 $x(\cdots)\to\dfrac{c-\tfrac{b^{2}}a}{2\sqrt a}=\dfrac{ac-b^{2}}{2a^{3/2}}$（该值只依赖 $\beta^{2}$，但合法性靠上一步筛掉负支）。
    - 自检：$y=\sqrt{x^2+1}$ 即 $a=1,b=0,c=1$：$\alpha=1,\beta=0$，$x(\sqrt{x^2+1}-x)\to\dfrac12$，公式给 $\dfrac12$ ✓。配方视角：$ax^2+2bx+c=\Bigl(\sqrt a\,x+\dfrac b{\sqrt a}\Bigr)^{2}+\dfrac{ac-b^{2}}{a}$，当 $b^2=ac$ 时根号内恰是完全平方、曲线与渐近线重合为一射线。

## 三、核心技巧速查表

| 技巧/结论 | 适用场景 | 记忆要点 |
|---|---|---|
| 连续三条件 | 判断某点是否连续 | 有定义 + 极限存在 + 极限=函数值 |
| 左右极限都算 | 分段函数分界点 | 连续 $\iff$ 左连续且右连续 |
| 可去间断 | 极限存在但 $\neq f(x_0)$ 或无定义 | 补充定义即连续 |
| 跳跃间断 | 左右极限存在但不相等 | 只差"一步"，无法抹平 |
| 无穷间断 | 至少一侧极限为 $\infty$ | 第二类，图形有垂直渐近线 |
| 振荡间断 | 极限因振荡不存在 | 第二类，如 $\sin\frac1x$ 在 $0$ 点 |
| $\lim_{x\to0}x\sin\frac1x=0$ | 无穷小 $\times$ 有界 | 有界量乘无穷小仍为无穷小 |
| $e^{1/x}$ 在 $0$ 点 | 判 $0$ 点间断 | 左极限 $0$、右极限 $+\infty$ |
| $\dfrac{x}{\|x\|}=\mathrm{sgn}\,x$ | 判 $0$ 点间断 | 左 $-1$、右 $+1$，跳跃 |
| 零点定理 | 证方程根的存在 | 闭区间连续 + 端点异号 $\Rightarrow$ $\exists\,\xi$ |
| 水平渐近线 | $\lim_{x\to\infty}f(x)=b$ | 双侧分别看，可能两条 |
| 垂直渐近线 | 无定义点处 $\lim f(x)=\infty$ | 候选点必须验证极限为无穷 |
| 斜渐近线 | $k=\lim\dfrac{f(x)}{x}$，$b=\lim[f(x)-kx]$ | $k\neq0$ 且有限；$k=0$ 退化为水平 |

## 四、易错点清单

- 判断连续时只求极限，漏掉"是否有定义"和"是否等于函数值"两个条件。
- 分段函数在分界点只算单侧极限，漏算另一侧。
- 把"可去间断点"误当成连续点（可去间断点本质是极限存在但函数值与极限不符或未定义）。
- 第二类间断点只记得无穷间断，漏掉振荡间断点。
- 求间断点时漏找无定义点（分母零点、$\ln$ 真数为零、$\tan x$ 无定义点、分段分界点等）。
- $e^{1/x}$ 在 $x=0$ 处左右极限不同，误判为无穷间断。
- 水平渐近线不分别考察 $x\to+\infty$ 与 $x\to-\infty$（两侧可能不同）。
- 求斜渐近线时先跳过 $k$ 直接求 $b$，或求 $b$ 时漏减 $kx$。
- 把"无定义点"直接当垂直渐近线，忘记验证极限是否为 $\infty$（若极限有限则为可去间断，无垂直渐近线）。
- 用零点定理时忽略"闭区间连续"与"端点异号"两个前提，或把"至少一个根"当成"唯一根"。
- 混淆介值定理与零点定理：零点定理是介值定理的特例（$f(a)f(b)<0$ 时必存在零点）。
