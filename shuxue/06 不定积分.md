# 06 不定积分

> **章节定位**：不定积分是定积分、变限积分、微分方程的共同工具基础，选择填空高频直接考计算，大题中作为中间步骤出现。核心是"凑微分、换元、分部积分、有理函数积分"四大方法（外加三角有理式），难点不在知识本身，而在**拿到题后选对方法**。

## 一、知识框架

- **原函数与不定积分**
  - 原函数：$F'(x)=f(x)$（$x\in I$）；**连续函数必有原函数**
  - 不定积分 $\displaystyle\int f(x)\,\mathrm dx=F(x)+C$ 是**全体原函数**，任意两个原函数只差常数
  - 运算关系：$\dfrac{\mathrm d}{\mathrm dx}\displaystyle\int f(x)\mathrm dx=f(x)$（先积后导不加 $C$）；$\displaystyle\int f'(x)\mathrm dx=f(x)+C$（先导后积要加 $C$）
- **基本积分表**：基本求导公式逐一逆过来（幂、指、对、三角、反三角）
- **四大核心方法**
  - **凑微分（第一类换元）**：$\displaystyle\int f[g(x)]g'(x)\,\mathrm dx=\int f[g(x)]\,\mathrm dg(x)=F[g(x)]+C$，链式法则的逆用，"把内层当整体"
  - **换元（第二类换元）**：主动引入 $x=\varphi(t)$ 消根号——一次根式整体代换，二次根式三角代换
  - **分部积分**：$\displaystyle\int u\,\mathrm dv=uv-\int v\,\mathrm du$，乘积求导的逆用，口诀"对反幂三指"
  - **有理函数积分**：约分 → 除法 → 因式分解 → 部分分式待定系数 → 逐项积，唯一机械通用的"兜底算法"
- **三角有理式 $R(\sin x,\cos x)$**：凑微分 → 变号测试选代换（$t=\cos x$ / $\sin x$ / $\tan x$）→ 万能代换 $t=\tan\frac x2$
- **必背积分结论**：$\int\frac{\mathrm dx}{x^2+a^2}$、$\int\frac{\mathrm dx}{x^2-a^2}$、$\int\frac{\mathrm dx}{\sqrt{a^2-x^2}}$、$\int\frac{\mathrm dx}{\sqrt{x^2\pm a^2}}$、$\int\sqrt{a^2-x^2}\,\mathrm dx$、$\int\tan x\,\mathrm dx$、$\int\sec x\,\mathrm dx$、$\int\csc x\,\mathrm dx$

## 二、常考题型

### 题型 1：凑微分法（第一类换元）

- **识别特征**：被积函数能看出 $f[g(x)]\cdot g'(x)$ 结构——"内层函数的导数（差个常数倍也行）就挂在外面"。
- **解题套路**：
  1. 找内层 $g(x)$，确认外面有其导数 $g'(x)$；
  2. 把 $g'(x)\,\mathrm dx$ 改写成 $\mathrm dg(x)$，内层整体当一个变量；
  3. 用基本积分表直接写出 $F[g(x)]+C$。不引入新字母、**不用换回**。
- **典型例题**：
  > (1) $\displaystyle\int\frac{\mathrm dx}{x(1+\ln x)}$：$\frac{\mathrm dx}{x}=\mathrm d(\ln x)=\mathrm d(1+\ln x)$，原式 $=\displaystyle\int\frac{\mathrm d(1+\ln x)}{1+\ln x}=\ln|1+\ln x|+C$。
  > (2) 抽象函数三件套：$\displaystyle\int e^{f(x)}f'(x)\mathrm dx=e^{f(x)}+C$；$\displaystyle\int\frac{f'(x)}{f(x)}\mathrm dx=\ln|f(x)|+C$；$\displaystyle\int\frac{f'(x)}{1+f^2(x)}\mathrm dx=\arctan f(x)+C$。
- **易错点**：凑完没把内层当整体（$\int\cos(x^2)\,\mathrm d(x^2)$ 写错成 $\sin x\cdot 2x$）；$\displaystyle\int f'(2x)\mathrm dx=\frac12f(2x)+C$，**要除以内层导数**，不能直接写 $f(2x)$。

### 题型 2：第二类换元法（去根号）

- **识别特征**：出现 $\sqrt{\text{一次式}}$、$\sqrt{\dfrac{\text{一次式}}{\text{一次式}}}$、$\sqrt{a\,\mathrm e^x+b}$ → 令整个根号等于 $t$；出现 $\sqrt{a^2-x^2}$、$\sqrt{a^2+x^2}$、$\sqrt{x^2-a^2}$ → 三角代换。
- **解题套路**：
  1. 一次根号：令 $t=$ 整个根号，反解 $x$、求 $\mathrm dx$，代入后根号消失；
  2. 二次根号：三角代换消根号——**减号配 $\sin$、加号配 $\tan$、平方差配 $\sec$**，依据 $1-\sin^2t=\cos^2t$、$1+\tan^2t=\sec^2t$、$\sec^2t-1=\tan^2t$；
  3. 算出 $t$ 的原函数后，**画直角三角形回代**成 $x$ 的式子（如 $x=a\tan t$ 时 $\sec t=\frac{\sqrt{x^2+a^2}}a$）。
- **典型例题**：
  > (1) $\displaystyle\int\frac{\mathrm dx}{\sqrt x(1+x)}$：令 $\sqrt x=t$，$\mathrm dx=2t\,\mathrm dt$，原式 $=\displaystyle\int\frac{2\,\mathrm dt}{1+t^2}=2\arctan\sqrt x+C$。
  > (2) $\displaystyle\int\frac{\mathrm dx}{\sqrt{x^2+4}}$：令 $x=2\tan t$，原式 $=\displaystyle\int\sec t\,\mathrm dt=\ln|\sec t+\tan t|+C=\ln\big(x+\sqrt{x^2+4}\big)+C$。
- **易错点**：算完忘把变量换回；$\sqrt{4-4\sin^2t}$ 开方直接写 $2\cos t$ 不说明（不定积分默认取 $\cos t>0$ 的单值支）；二次根号硬令根号 $=t$——反解 $x$ 后 $\mathrm dx$ 里又冒根号，等于白换。

### 题型 3：分部积分法

- **识别特征**：**不同种类的函数相乘**（$xe^x$、$x\ln x$、$x\cos x$ 等）；$\ln x$、$\arctan x$、$\arcsin x$ 单独出现也用分部（把 $\mathrm dx$ 看作 $\mathrm dv$）。
- **解题套路**：
  1. 按"**对反幂三指**"（对数、反三角、幂、三角、指数）排序；
  2. **谁排在后面就把谁凑进 $\mathrm d$**，排在前面的留作 $u$ 被求导（"谁怕求导就对谁求导"：对数、反三角求导后变简单）；
  3. 写 $\int u\,\mathrm dv=uv-\int v\,\mathrm du$，算新积分。
- **典型例题**：
  > (1) $\displaystyle\int x\ln x\,\mathrm dx=\int\ln x\,\mathrm d\Big(\frac{x^2}2\Big)=\frac{x^2}2\ln x-\int\frac x2\,\mathrm dx=\frac{x^2}2\ln x-\frac{x^2}4+C$。
  > (2) $\displaystyle\int\ln x\,\mathrm dx=x\ln x-\int x\cdot\frac1x\,\mathrm dx=x\ln x-x+C$。
- **易错点**：口诀用反（把 $\ln x$ 凑进 $\mathrm d$ 越积越复杂）；$uv$ 项与 $\int v\,\mathrm du$ 里的系数、符号抄错。

### 题型 4：循环积分（三角 × 指数）

- **识别特征**：$\displaystyle\int e^{ax}\sin bx\,\mathrm dx$、$\displaystyle\int e^{ax}\cos bx\,\mathrm dx$——两类函数都"不怕求导"，一次分部无法简化。
- **解题套路**：
  1. 连续两次分部积分，**两次必须凑同一类函数**（都凑三角，或都凑指数）；
  2. 第二次分部后右边重现原积分 $I$（积分重现），得到关于 $I$ 的一元一次方程；
  3. 解方程求 $I$，**最后必须补 $+C$**。
- **典型例题**：
  > $I=\displaystyle\int e^x\sin x\,\mathrm dx$，两次都凑 $e^x$：$I=e^x\sin x-\displaystyle\int\cos x\,\mathrm de^x=e^x\sin x-\big(e^x\cos x+I\big)$，故 $2I=e^x(\sin x-\cos x)$，**$I=\frac{e^x}2(\sin x-\cos x)+C$**。
- **易错点**：两次凑的对象不同类（一次凑 $e^x$、一次凑 $\sin x$），右边变回 $I=I$ 循环作废；解出 $I$ 后忘写 $C$。

### 题型 5：有理函数积分（部分分式分解）

- **识别特征**：被积函数是多项式之比 $\frac{P(x)}{Q(x)}$。
- **解题套路**（四步流水线）：
  1. **先约分**；若 $\deg P\ge\deg Q$，先多项式除法化成"多项式 + 真分式"（多项式直接逐项积）；
  2. 分母在实数范围内分解为**一次因式幂 + 不可约二次因式幂**（$\Delta=p^2-4q<0$）；
  3. 按规则写部分分式，待定系数：**先赋值代分母的根**，剩下系数用比较同一幂次补齐；重因式 $(x-a)^k$ **每层都要写** $\frac{A_1}{x-a}+\cdots+\frac{A_k}{(x-a)^k}$；
  4. 逐项积：$\frac A{x-a}\to A\ln|x-a|$；$\frac A{(x-a)^k}\to$ 幂函数；$\frac{Ax+B}{x^2+px+q}\to$ 分子拆成"$\frac A2\times$分母导数 $+$ 常数"，前者出 $\ln$，后者**配方**出 $\arctan$。
- **典型例题**：
  > (1) $\displaystyle\int\frac{2x^3+1}{x^2+x}\mathrm dx$：除法 $2x^3+1=(2x-2)(x^2+x)+(2x+1)$；$\frac{2x+1}{x(x+1)}=\frac1x-\frac1{x+1}$（赋值 $x=0,-1$）。**答案 $x^2-2x+\ln\left|\dfrac x{x+1}\right|+C$**。
  > (2) $\displaystyle\int\frac{x-2}{x^2+2x+3}\mathrm dx$：$\Delta<0$ 不可约；$x-2=\frac12(2x+2)-3$，配方 $x^2+2x+3=(x+1)^2+2$。**答案 $\frac12\ln(x^2+2x+3)-\frac3{\sqrt2}\arctan\frac{x+1}{\sqrt2}+C$**。
- **易错点**：假分式不做除法直接拆；$(x-1)^2$ 漏写 $\frac B{x-1}$ 层，方程组无解；一次因式取对数忘加绝对值，二次不可约因式恒正**不加**绝对值。

### 题型 6：三角有理式积分

- **识别特征**：被积函数是 $R(\sin x,\cos x)$ 型。
- **解题套路**（由巧到拙，四层漏斗）：
  1. 有 $\sin x\cdot f(\cos x)$ 或 $\cos x\cdot f(\sin x)$ 结构 → 凑微分；$\sin^m x\cos^nx$：**奇次幂拆一个凑微分，全偶次用降幂公式**；
  2. 变号测试：关于 $\sin$ 奇（$R(-\sin,\cos)=-R$）→ $t=\cos x$；关于 $\cos$ 奇 → $t=\sin x$；**同时变号不变**（$R(-\sin,-\cos)=R$）→ 分子分母同除 $\cos^2x$，令 $t=\tan x$；
  3. 特殊结构：分母 $a\sin x+b\cos x$ → 辅助角公式；含 $1\pm\sin x$、$1\pm\cos x$ → 乘共轭；不同频率相乘 → 积化和差；
  4. 都不行 → **万能代换** $t=\tan\frac x2$，化成有理函数积分。
- **典型例题**：
  > (1) $\displaystyle\int\frac{\mathrm dx}{1+\sin^2x}$：同除 $\cos^2x$，$=\displaystyle\int\frac{\mathrm d(\tan x)}{1+2\tan^2x}=\frac1{\sqrt2}\arctan(\sqrt2\tan x)+C$。
  > (2) $\displaystyle\int\frac{\mathrm dx}{3+\cos x}$：变号测试全不过，万能代换 $\sin x=\frac{2t}{1+t^2},\ \cos x=\frac{1-t^2}{1+t^2},\ \mathrm dx=\frac{2\,\mathrm dt}{1+t^2}$，化简得 $\displaystyle\int\frac{\mathrm dt}{2+t^2}$。**答案 $\frac1{\sqrt2}\arctan\frac{\tan(x/2)}{\sqrt2}+C$**。
- **易错点**：跳过测试直接上万能代换（计算量爆炸）；$\frac1{5+4\cos x}$ 误用 $t=\tan x$——把 $\cos$ 换成 $-\cos$ 后式子变了，不满足"同时变号不变"。

### 题型 7：分段 / 绝对值函数的不定积分

- **识别特征**：被积函数含 $|x|$、$\max$、$\min$ 或分段表达式。
- **解题套路**：
  1. 去绝对值，写成分段函数；
  2. 各段分别积分（各带任意常数）；
  3. **利用原函数在分界点连续**（可导 ⇒ 连续）确定各段常数关系，拼成统一表达式。
- **典型例题**：
  > $\displaystyle\int|x|\,\mathrm dx$：$x\ge0$ 时 $\frac{x^2}2+C_1$，$x<0$ 时 $-\frac{x^2}2+C_2$；由 $x=0$ 处连续得 $C_1=C_2$。**答案 $\frac12\,x|x|+C$**。
- **易错点**：两段各写各的 $C$ 不拼接；拼完不回头验证分界点连续。

### 题型 8：原函数与不定积分的概念题

- **识别特征**：选择题辨析 $\frac{\mathrm d}{\mathrm dx}\int f\,\mathrm dx$ 与 $\int f'\,\mathrm dx$、复合的积分 $\int f'(2x)\mathrm dx$、原函数存在性。
- **解题套路**：
  1. 先导后积要 $+C$：$\int f'(x)\mathrm dx=f(x)+C$；先积后导不加 $C$：$\big(\int f\,\mathrm dx\big)'=f(x)$；
  2. 内层是复合要除内层导数：$\displaystyle\int f'(2x)\,\mathrm dx=\frac12f(2x)+C$；
  3. 存在性：**连续 ⇒ 有原函数**；**含跳跃间断点 ⇒ 无原函数**（原函数必可导必连续，左右原函数拼不上）。
- **典型例题**：
  > 判断：$f(x)=\begin{cases}-1,&x<0\\1,&x\ge0\end{cases}$ 在含 $0$ 的区间上有无原函数？
  > 解：**无**。若 $F$ 是原函数，则 $x<0$ 时 $F=-x+C_1$，$x\ge0$ 时 $F=x+C_2$；连续要求 $C_1=C_2$，但此时 $F$ 在 $0$ 处左导数 $-1\neq$ 右导数 $1$，与 $F'(0)=f(0)=1$ 矛盾。
- **易错点**：$\int f'(2x)\mathrm dx$ 忘除 $2$；把"f 有原函数 ⇒ f 连续"当真——导函数可以有（第二类）间断点，但**跳跃间断必无原函数**这条是对的。

## 三、核心技巧速查表

| 技巧/结论 | 适用场景 | 记忆要点 |
|---|---|---|
| $g'(x)\,\mathrm dx=\mathrm dg(x)$ | 一切凑微分 | 内层的导数在外面 → 内层整体当变量 |
| 常用凑微分：$\frac{\mathrm dx}x=\mathrm d\ln\vert x\vert$、$x^{n-1}\mathrm dx=\frac1n\mathrm d(x^n)$、$e^x\mathrm dx=\mathrm de^x$、$\frac{\mathrm dx}{1+x^2}=\mathrm d\arctan x$、$\frac{\mathrm dx}{\sqrt{1-x^2}}=\mathrm d\arcsin x$ | 对应结构出现时 | 都是基本求导公式倒着写 |
| 抽象函数三件套 | $\int e^ff'$、$\int\frac{f'}f$、$\int\frac{f'}{1+f^2}$ | 结果 $e^f$、$\ln\vert f\vert$、$\arctan f$ |
| 一次根式代换 | $\sqrt{ax+b}$、$\sqrt{\frac{ax+b}{cx+d}}$、$\sqrt{ae^x+b}$ | 整个根号令 $t$，算完换回 |
| 三角代换 | $\sqrt{a^2-x^2}\to a\sin t$；$\sqrt{a^2+x^2}\to a\tan t$；$\sqrt{x^2-a^2}\to a\sec t$ | 减 $\sin$、加 $\tan$、平方差 $\sec$；画直角三角形回代 |
| 必背结论：$\int\frac{\mathrm dx}{x^2\pm a^2}$、$\int\frac{\mathrm dx}{\sqrt{a^2-x^2}}=\arcsin\frac xa+C$、$\int\frac{\mathrm dx}{\sqrt{x^2\pm a^2}}=\ln\vert x+\sqrt{x^2\pm a^2}\vert+C$、$\int\sqrt{a^2-x^2}\mathrm dx=\frac{a^2}2\arcsin\frac xa+\frac x2\sqrt{a^2-x^2}+C$ | 填空/中间步骤 | $x^2-a^2$ 型 $\frac1{2a}\ln\vert\frac{x-a}{x+a}\vert$；扇形面积公式 |
| 分部积分 | 不同类函数相乘 | $\int u\mathrm dv=uv-\int v\mathrm du$；"对反幂三指"，**排后面的凑进 d** |
| 循环积分 | $e^{ax}\times\sin/\cos bx$ | 两次**同向**凑，解方程，补 $C$ |
| 有理函数四步 | $\frac{P(x)}{Q(x)}$ | 约分 → 除法 → 分解 → 待定系数 → 逐项积 |
| 部分分式规则 | 拆分 | 一次因式每层一个砖块；不可约二次分子带 $Ax+B$ |
| 三角有理式变号测试 | $R(\sin x,\cos x)$ | $\sin$ 奇 → $t=\cos x$；$\cos$ 奇 → $t=\sin x$；双偶 → $t=\tan x$；否则万能代换 |
| 万能代换 | 兜底 | $\sin x=\frac{2t}{1+t^2}$、$\cos x=\frac{1-t^2}{1+t^2}$、$\mathrm dx=\frac{2\mathrm dt}{1+t^2}$ |

## 四、易错点清单

- 换元法算完**忘把变量换回** $x$（最常见扣分点）。
- 三角换元不画直角三角形硬回代，或开方不说明符号。
- 一次因式取对数**忘加绝对值**；二次不可约因式恒正，不必加。
- 假分式**不先做多项式除法**就拆部分分式。
- 重因式 $(x-a)^k$ 漏写中间层，待定系数方程组出现矛盾。
- 循环积分两次凑的函数**不同类**，循环作废；解出 $I$ 后忘 $+C$。
- $\displaystyle\int f'(2x)\,\mathrm dx=\frac12f(2x)+C$，不是 $f(2x)+C$（链式法则陷阱）。
- 分段/绝对值函数各段积分后**不用连续性拼常数**。
- 有理函数拆分前不先**约分**；分子恰是分母导数倍数时还死拆（应直接凑微分）。
- 万能代换当首选，计算量大、易错；应先凑微分、再变号测试。
- 结果**丢 $+C$**；概念题中"全体原函数"与"某一个原函数"混淆。
