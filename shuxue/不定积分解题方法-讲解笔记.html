不定积分的解题方法

高数上册进阶 · 讲义讲解笔记

这份笔记不重抄讲义，只做一件事：把讲义里散落的二十多种技巧，归并到几条判据下面，说清每条技巧由哪条判据推出、在什么条件下失效。

0导言：这套方法在解决什么问题

不定积分这一章的难点从来不是"会不会积分"，而是面对一个陌生的被积函数，能不能在三秒内判断该走哪条路。基本积分表、基本换元、分部积分公式是工具；讲义真正在教的，是一张"路标图"——什么长相的式子对应什么动作。

三条前提（讲义默认你已经具备）

  1. 基本积分表、凑微分、第一/第二类换元、分部积分公式已熟练，不需要现查。
  2. 有理函数理论上一定能积（待定系数法），但"一定能积"不等于"该这么积"。例题 2 用待定系数法要解四元方程组，例题 3 只需三次减法。
  3. 三角有理函数理论上一定能积（万能代换 t = tan(x/2)），同样不等于最快。例题 27 用万能代换要算到四次有理式，造出 d(tan x) 只需两行。

适用的边界

  • 全部手法服务于三个目标：去根号、降分母次数、把分子凑成某个可识别对象的导数。看不出结构信号的题（个别根式题），只能靠"试换元"，这是正常的。
  • 判据通用，但每个具体换元选谁由题目结构给信号。没有信号时，优先试"令整个根号等于 t"和"倒代换"两条通用策略。
  • 三角有理函数的六条特殊解法，数三原则上不要求；但其中"对称性三判据"本身是极高效的思维工具，仍值得掌握。
  • 讲义中"考法四"编号缺失（原文从考法三直接跳到考法五），本笔记沿用原文编号，不做补正。

一判据层：五条不可动摇的心法

讲义里 34 道例题、上百个技巧，都可以由下面五条判据生成。先记判据，再记技巧；判据想清楚了，技巧是自然产物。

判据 1　先看结构，再动手

被积函数的长相决定手法，不是反过来。看到根号 → 想"怎么去根号"；看到高次分母 → 想"怎么降阶"；看到分母是平方 → 想"分部降阶"；看到 ex 乘有理式 → 想"抵消"。动手之前先给式子贴一个标签。

判据 2　全部动作只有三个目的

去根号 · 降分母次数 · 把分子凑成某个可识别对象的导数。

任何一步变形若不属于这三类，就要怀疑这一步是不是白做——它既没让式子更简单，也没让结构更明显。

判据 3　分部积分只有两种用法

用法 A（降阶）：把分母凑到 d 后面，一次分部让分母次数降下来。识别信号：分母是高次幂，如 1/(1+x)2、1/(a2+x2)2。

用法 B（抵消）：把一个积分拆成 I1 + I2，只对 I2 分部，分部后产生的新积分恰好是 −I1，两者相消。识别信号：被积函数里有 ex（或 ef(x)）与有理式相乘，或整体是两个函数的乘积结构。

判据 3 是这份讲义里回报最高的一条：例题 15、16、17、18，四条支线全由它生出。

判据 4　求导试探法

把被积函数里最复杂的那个因子求一次导，看结果是否出现在分子上。若出现，整个积分立刻变成一个 ∫g′/g 或 ∫g′/(1+g) 型。

这是所有"巧题"的统一生成机制——包括讲义里那个出题模板。它不是灵感，是例行检查动作。

判据 5　三角有理函数的对称性三判据

对 ∫R(sin x, cos x) dx，逐个检查三件事：

  • R(sin x, −cos x) = −R(sin x, cos x) → 把 cos x 凑进 d，凑出 d(sin x)；
  • R(−sin x, cos x) = −R(sin x, cos x) → 把 sin x 凑进 d，凑出 d(cos x)；
  • R(−sin x, −cos x) = R(sin x, cos x) → 分子分母同除 cos²x 造出 sec²x dx = d(tan x)。

三条全不满足 → 万能代换 t = tan(x/2) 兜底。前三条都成立（如 1/(sin x cos x)）→ 三条路都走得通，选最短的。

二讲 1　分段函数的不定积分（考法一）

核心判据

分段积分不难，难的只有一处：拼接点的常数要让原函数连续。这不是"再检查一遍"，而是解题本身的最后一步。

原理拆解：为什么必须调常数

在每段上分别积分，会各自带一个任意常数 C1、C2，看起来是两个自由度。但"F 是 f 的原函数"这句话本身含有 F 可导、因而连续的要求。原函数连续 ⟹ 两个常数被一个方程联系，真正的自由度仍然只有一个。

注意：只要求连续，不要求可导。可导性由被积函数 f 在分界点是否连续决定——若 f 本身在分界点连续，则原函数自动可导；若 f 有跳跃，原函数只在分界点左右连续而不可导，这才是正确结果。拿"原函数可导"当检查条件是常见误判。

原文判词

设 f(x) 分段给出，求 ∫f(x)dx。 ——2016 年真题，考法一的唯一代表题型

示例推演：例题 1（2016）

设 f(x) = 2(x−1) (x < 1)，= ln x (x ≥ 1)，求 ∫f(x)dx。

x < 1 段：∫2(x−1)dx = (x−1)2 + C1
x ≥ 1 段：∫ln x dx = x ln x − x + C2

在 x = 1 处令左右极限相等（左段在 1 处的值由函数式直接代入，右段同理）：

C1 = (−1) + C2　⟹　C2 = C1 + 1

把 C2 换掉、统一写成 C 即得结果。这里 f 在 x = 1 处连续（2·0 = ln 1 = 0），所以原函数在该点其实可导，但我们不需要检查这一条。

常见误区

  • 两段各写一个 C 就交卷，没做拼接。这是本考法唯一会扣分的点。
  • 去做"原函数在分界点可导"的验证。多余，且当 f 有跳跃时会得出"题目有误"的错误结论。
  • 拼接时用了右段的整个表达式而不代入具体数值，比如写 C1 = x ln x − x + C2。必须把 x = 1 代进去。

三讲 2　有理函数的积分（考法二）

核心判据

有理函数有两条通道：待定系数法（保底，一定成功但可能很累）与巧妙裂项（改造分子／倒代换，快但需要看出结构）。先花十秒找结构，找不到再上待定系数。

原理拆解：为什么"巧妙裂项"存在

待定系数法的代价随分母因式的重数、二次因式的个数迅速膨胀——例题 2 要解四元一次方程组，中间任何一步算错都要重来。而"巧妙裂项"利用的是分子分母之间的代数恒等式（如 1 = (1+x2) − x2），把高次分母逐层剥掉。它的效率来自结构，代价是必须看出来。

所以正确的工作顺序是：先扫一遍分母的因式结构 → 判断能否三步内拆掉 → 拆不动再上待定系数。待定系数法不是"笨办法"，是"兜底办法"。

通道 A：待定系数法裂项

例题 2：∫(30x2+40x−50)/((x−2)2(x2+2x+2))dx。

拆解动作分四步，注意第 2 步是省一半计算量的关键：

  1. 设形：A/(x−2) + B/(x−2)2 + (Cx+D)/(x2+2x+2)。二次因式（判别式 < 0，不可再分解）必须配一次式的分子。
  2. 用"代入根"先定一个系数：两边乘 (x−2)2 后令 x = 2，左边只剩 B，直接得 B = 15，省掉一个未知量。重因式的最高次项系数永远能这样秒出。
  3. 补齐全式，比对 x3、x2、x、常数四项，解出 A = 7、C = −7、D = −13。
  4. 收尾：把二次因式配方成 (x+1)2+1，把 −7x−13 改写成 −7(x+1) − 6，于是自动分裂成"对数项 + 反正切项"两类基本积分。
结果：7ln|x−2| − 15/(x−2) − (7/2)ln(x2+2x+2) − 6arctan(x+1) + C

第 4 步的改写 −7x−13 = −7(x+1)−6 是二次因式收尾的标准动作：配方式的后半段一定要用"一次项凑成配方内部的导数"这个形式，否则无法直接积。

通道 B：其他方法巧妙裂项

B-1　改造分子：利用 1 = (1+x2) − x2

例题 3：∫1/(x6(1+x2))dx。核心动作是把恒等式 1 = (1+x2) − x2 当"减一层"的工具，反复使用：

1/(x6(1+x2)) = 1/x6 − 1/(x4(1+x2))
1/(x4(1+x2)) = 1/x4 − 1/(x2(1+x2))
1/(x2(1+x2)) = 1/x2 − 1/(1+x2)

三行拆到底，剩下四个幂函数积分和一个 arctan，直接写答案。整个过程只用了减法和记忆中的幂函数积分表。

动作提炼：分母出现 xn(1+x2) 这个组合，第一反应就是在分子上写 (1+x2) − x2。每用一次，分母的 x 的次数降 2。

类题 1：∫(1+2x4)/(x3(1+x4)2)dx。同一族但更绕，先把分子拆成 1 与 2x4 两块，再对上式用一次 1 = (1+x4) − x4，最终完全化为幂函数与 arctan(x2) 的组合。这一题的价值是让你看清：同一恒等式配不同的指数组合，能吃掉一整族题。

类题 2：∫(1+x4)/(1+x6)dx。这题不靠减一层，靠的是把分子改写成分母的因式组合：

1 + x6 = (1+x2)(x4−x2+1)，而 1 + x4 = (x4−x2+1) + x2
被积式 = 1/(1+x2) + x2/(1+x6)

后一项凑 d(x3)（因为 d(x3) = 3x2dx），化为 arctan 型。答案 arctan x + (1/3)arctan(x3) + C。动作提炼：分母是 1+x6，先想 1+x6=(1+x2)(1−x2+x4)，再看分子能不能配成这两块的组合。

B-2　倒代换：分母次数远高于分子时

例题 4 与例题 3 是同一道题（讲义在此处重复收录，正是为了对照两种解法）。用 x = 1/t 走一遍：

1/(x6(1+x2)) · dx = −t6/(1+t2) dt

换来的是一个假分式，做一次多项式除法即得 t4 − t2 + 1 − 1/(1+t2)，逐项可积。结果与例题 3 相同（差一个常数，来自 arctan(1/t) 与 −arctan t 的关系，在 x > 0 上成立）。

两条通道的取舍：改造分子保留原变量，步骤少但要求看出恒等式；倒代换机械可靠，代价是要做多项式除法并把答案换回原变量。看到"分母次数比分子高 4 次以上"就优先考虑倒代换。

常见误区

  • 见到有理函数就直接上待定系数，错过三行减法能解决的题。
  • 待定系数时设错形：二次因式（判别式 < 0）的分子必须是 Cx+D 而不能只写常数；重因式的每一重都要单独设项。
  • 倒代换后忘记把答案换回 x，或换回时把 √ 的符号弄错。
  • 分母是 1+x4 却去硬做因式分解（见讲 3）。

四讲 3　1/(1+x4) 家族（考法二·三）

核心判据

分母出现 1 + kx2 + x4 这类"首尾对称"的四次式，一律走同一条路：分子配成 1 ± x2，然后上下同除 x2，把式子整理成关于 x ± 1/x 的函数。这不是技巧，是一族题的统一母法。

原理拆解：为什么是"配 1 ± x2"

关键的代数事实有两条：

  • 上下同除 x2 后，x2 + 1/x2 = (x − 1/x)2 + 2——分母变成 x − 1/x 的二次式；
  • 而 d(x − 1/x) = (1 + 1/x2)dx，恰好对应分子 1 + x2 同除 x2 后的结果。

两条一拼，就得到"分子即分母所配变量的导数"这一完美结构。同理，分子取 1 − x2 时得到的是 x + 1/x（因为 d(x + 1/x) = (1 − 1/x2)dx，而 x2+1/x2 = (x+1/x)2 − 2）。两个分子各配一个变量，这不是巧合，是恒等式配对。

原文判词

本题非常经典，通过这个题目，我们可以解决所有形如 ∫(1 ± x2)/(1 + kx2 + x4) dx 的积分。 ——讲义例题 5 注 1
也可因式分解，1+x4 = (1+x2)2 − 2x2 = (1+x2+√2 x)(1+x2−√2 x)，但计算量大。 ——讲义例题 5 注 2。这条注记本身就是判据：看到四次分母，先问"能不能不分解成两个二次因式"

示例推演：例题 5 与类题 1

例题 5：∫(1+x2)/(1+x4)dx。上下同除 x2：

被积式 = (1 + 1/x2) / (x2 + 1/x2) = (1 + 1/x2) / ((x − 1/x)2 + 2)

令 t = x − 1/x，则分子整体即 dt：

∫dt/(t2+2) = (1/√2)arctan(t/√2) + C，t = x − 1/x

类题 1：∫(1−x2)/(1+x4)dx。同样除 x2：

被积式 = −(1 − 1/x2) / ((x + 1/x)2 − 2)
令 u = x + 1/x：−∫du/(u2−2) = −(1/(2√2))ln|(u−√2)/(u+√2)| + C

两式相加减即得讲义反复提到的那条副产品——这也是整个"配对法"最漂亮的地方：

∫1/(1+x4)dx = (1/2)[上式一 + 上式二]
= (1/(2√2))arctan((x2−1)/(√2 x)) + (1/(4√2))ln|(x2−√2 x+1)/(x2+√2 x+1)| + C

注意 (x − 1/x)/√2 = (x2−1)/(√2 x)，这是回代时最容易写错的一步。

推广：例题 6 ∫√(tan x)dx

这题表面与 1+x4 无关，实际被归入同一族。令 t = √(tan x)，则 tan x = t2，x = arctan(t2)，dx = 2t/(1+t4) dt：

∫√(tan x)dx = ∫ t · 2t/(1+t4) dt = 2∫ t2/(1+t4) dt

而 t2/(1+t4) = (1/2)[(1+t2)/(1+t4) − (1−t2)/(1+t4)]，正是刚做完的两块之差，直接抄结果即可。

动作提炼：凡是被积函数里有 tan x、且只以 √(tan x) 或 tan x 的形式出现，先试 t = √(tan x)；代换后若出现 1+t4，立刻调出本讲的母法。

类题 2：∫1/(1+x6)dx

不能直接套母法（分母是六次），但可以先降成"两个已知块"的和：设 1/((1+x2)(1−x2+x4)) = (A+Bx)/(1+x2) + (C+Dx2)/(1−x2+x4)，比对得 A = C = 1/2、B = 0、D = −1/2，于是

∫1/(1+x6)dx = (1/2)arctan x − (1/(4√3))ln|(x2−√3 x+1)/(x2+√3 x+1)| + C

第二块用的还是"配 1−x2 + 同除 x2"，只是常数从 2 变成 3。这再一次说明：母法管的是"分子是分母配变量的导数"，分母的具体常数只影响最后一步的基本积分表查表。

常见误区

  • 去硬做因式分解 (1+x2+√2 x)(1+x2−√2 x)，然后待定系数。算得出来，但四元方程组 + 两个二次因式的收尾，是例题 5 的十几倍工作量。
  • 只记住"同除 x2"，忘了分子必须先写成 1 ± x2。若分子不是这个形状（如 ∫x2/(1+x4)dx），要先用恒等式拆成两个标准分子的组合。
  • 回代时把 (x−1/x)/√2 写成 (x2−1)/(√2 x2) 之类的形式。
  • 把"配对法"当成只对 1+x4 有效。它对 1+kx2+x4（k 任意）一律有效。

五讲 4　换元法：如何去掉根号（考法三·一）

核心判据

换元的唯一验收标准是：换完以后根号消失了。讲义给的四条套路只是最常命中的四种情形，不是必须遵守的规矩。

四条套路（讲义原文）

根号内的形状换元动作
√(一次函数)令整个根号 = t
√(一次函数 / 一次函数)令整个根号 = t
√(a·ex + b)令整个根号 = t
√((a·ex+b)/(c·ex+d))令整个根号 = t

四条的共同动作都是同一句：令整个根号等于 t，然后反解出 x。反解出来后 ex、x 都变成 t 的有理式，dx 也变成有理式。这就是"根式 → 有理式"的标准通道。

原文判词

不必完全拘泥于上面的套路，只要我们的换元是能够去掉根号的就可以了。 ——讲义考法三（一）。这句话是全讲最重要的判据，以下是四个"不走套路"的示范

示例推演：例题 10（教材）

∫1/∛((x+1)2(x−1)4) dx。写成幂函数形式看结构：

(x+1)−2/3(x−1)−4/3

指数分母都是 3，且两个一次因式的指数和为 −2（不是 −1，所以不是简单的 t = 根号可比）。采用"令两个因式之比开三次方"的动作：

令 t = ∛((x−1)/(x+1))　⟹　x = (1+t3)/(1−t3)

由这个 x 反解式可以算出 x+1 = 2/(1−t3)、x−1 = 2t3/(1−t3)。代回后所有分式因式全部相消：

被积式 = (3/2) t−2 dt　⟹　积分 = −3/(2t) + C = −(3/2)·∛((x+1)/(x−1)) + C
动作提炼：根号里是两个一次因式的幂、且指数之差恰好是 1（即分母相同）时，令它们的比值开那个次方。这是套路之外最有价值的一条。

另外三个不走套路的示范（结构与关键一步）

例题 7：∫1/√(x3(1−x)) dx。根号里含 x3，倒代换 x = 1/t 后根号整体塌缩：

被积式 = −dt/√(t−1)　⟹　答案 = −2√((1−x)/x) + C

例题 8：∫1/(√2 + √(1+x) + √(1−x)) dx。这里换元不是首选，有理化才是：注意到 (√(1+x)+√(1−x))2 − 2 = 2√(1−x2)，分子分母同乘 (√(1+x)+√(1−x)−√2)，分母立刻变成 2√(1−x2)，剩下的两块是 ∫dx/√(1±x)：

答案 = √(1+x) − √(1−x) − (√2/2)arcsin x + C

例题 9：∫01 arcsin√x / √(x(1−x)) dx。这题不要动根号，动 arcsin：令 t = arcsin√x，则 √x = sin t、x = sin²t、dx = 2 sin t cos t dt，而 √(x(1−x)) = sin t cos t。整个被积式塌缩成 2t dt：

∫0π/2 2t dt = π2/4
动作提炼：见到 arcsin 与 √(x(1−x)) 同时出现，令 t = arcsin√x 或 x = sin²t——因为 √(x(1−x)) 正是 sintcost，而 dx 中的 2sin t cos t 会把它约掉。

常见误区

  • 换元后忘记换积分限（定积分），或忘记把答案换回原变量（不定积分）。
  • 死守"根号 = t"的套路，在 √(x3(1−x)) 这种"根号里是乘积的高次幂"的题上撞墙。这类的信号是根号内是乘积而不是单个一次式，此时倒代换或有理化更有效。
  • 把 arcsin 当成障碍物想先消掉它。例题 9 里 arcsin 恰恰是钥匙，因为它的反函数能把 √(x(1−x)) 一起带走。
  • 换元方向搞反：例题 10 令的是比值 ∛((x−1)/(x+1))，不是 ∛(x−1) 或 ∛((x+1)(x−1))。

六讲 5　分部积分的四种用法（考法三·二三四五）

讲 5 是整份讲义的重心。分部积分不是"照公式套"，而是有四种彼此独立的战术用途。分辨它们，靠的是看被积函数的形状。

用法零：在 d 后加上恰当的常数

核心判据

当 ∫v dx 本身不方便时，取 ∫v dx = V + a（任意常数 a），分部公式依然成立。选 a 的标准是：让下一步的 ∫(V+a)·u′dx 尽量简单。

例题 11：∫x·ln(1+x2)·arctan x dx。dx 配 x 时，取 V = (1+x2)/2（而不是 x2/2）。这样下一步要积的式子是

∫(1+x2)/2 · [2x/(1+x2)·arctan x + ln(1+x2)/(1+x2)] dx

第一项的 (1+x2) 与分母精确相消，只剩 ∫x arctan x dx——一个已知的基本题。若当初取 x2/2，这个相消就不会发生，后面要多花一倍篇幅。

动作提炼：被积函数里有 1+x2 及其导数 2x 的影子时，d 后面配 (1+x2)/2。这条与"配方收尾""配对法"是同一个思想的三种面孔。常数自由度是白送的，不用白不用。

用法一：既要换元、又要分部（重点）

核心判据

换元把式子变成 ∫(t 的多项式)·(反三角或对数) dt 之后，不要再回代，直接在这个 t 世界里分部。

原文判词

解出 x = 1/(t2−1) 后，千万不要将 dx 具体计算出来，而应该直接分部积分。 ——讲义例题 13 注。不要把 x 与 dx 换成 t 与 dt，而是把整个 dx 换成含 dt 的表达式后再分部

示例推演：例题 12（2018）

∫e2x arctan√(ex−1) dx。令 t = √(ex−1)：

ex = 1+t2，dx = 2t/(1+t2)dt，e2x = (1+t2)2
被积式 = 2t(1+t2)arctan t dt

此时指数函数、根号全部消失，只剩"多项式 × arctan"——这正是分部的标准长相。取 u = arctan t、dv = 2t(1+t2)dt，则 v = t2 + t4/2：

= (t2+t4/2)arctan t − ∫(t2+t4/2)/(1+t2)dt

后一个积分做一次多项式除法即得 (1/2)(1+t2) − (1/2)/(1+t2)，逐项可积。最后回代 t = √(ex−1)，注意 (1+t2)2 = e2x，答案可以写得很干净：

= (1/2)e2xarctan√(ex−1) − (1/2)√(ex−1) − (1/6)(ex−1)3/2 + C

类题：∫√(x−1)·arctan√(x−1)/x dx。同样令 t = √(x−1)，被积式变成 2t2arctan t/(1+t2)。这次的分部前先做一步拆分：

2t2/(1+t2) = 2 − 2/(1+t2)

于是第一块是 ∫2arctan t dt（分部），第二块是 −2∫arctan t/(1+t2)dt（凑 d(arctan t)，根本不用分部）。答案含 −ln x 与 −(arctan√(x−1))2。动作提炼：换元后先做一次假分式拆分，往往能把"难积的一块"变成"已知的一块"。

例题 13（2009）：∫ln(1+√((1+x)/x))dx（x > 0）。令 t = √((1+x)/x)，反解得 x = 1/(t2−1)，由此 dx = −2t/(t2−1)2 dt。这时不急着把对数里的 x 也代换，而是直接把 1/(t2−1) 当作分部中的 v：

∫ln(1+t)·[−2t/(t2−1)2]dt = ln(1+t)/(t2−1) − ∫dt/((t2−1)(1+t))

因为 d[1/(t2−1)] = −2t/(t2−1)2，v 不需要算积分就现成了。剩下的有理函数拆成 (1/4)/(t−1) − (1/4)/(t+1) − (1/2)/(t+1)2，逐项可积。这题的教益是：当 dx 换出来的是一个现成导数时，"换元"与"分部"可以一次完成。

用法二：利用分部积分对分母降阶

核心判据

分母次数太高时，除了倒代换，还有第二条路：把分母凑到 d 后面，然后分部。分母降一次，分子升一次。适用信号：分母是平方或更高次，且分子里含 ex 这类"求导不变形"的因子。

这是基础篇 ∫x2/(a2+x2)2dx 的推广。例题 14：∫xex/(1+x)2dx。

取 u = xex，dv = dx/(1+x)2　⟹　v = −1/(1+x)
= −xex/(1+x) + ∫(x+1)ex/(1+x) dx = −xex/(1+x) + ex + C = ex/(1+x) + C

关键在 (xex)′ = (x+1)ex 恰好含因子 (x+1)，与降阶后剩下的 1/(1+x) 相消。这就是判据：选 u 时，让它的导数能约掉降阶后的分母。

用法三：利用分部积分实现"积分抵消"

核心判据

把一个积分拆成 I1 + I2，I1 不动，I2 分部，分部产生的新积分恰好是 −I1，两者相消。被积函数中"一般"含有指数函数。

原文判词

本题的背景是 ∫ex[f(x) + f′(x)]dx = exf(x) + C。 ——讲义例题 15 注。这个恒等式是"抵消"战术的母公式

母公式的推导本身就是"拆成两块、一块分部"的演示：∫exf′dx 分部后得到 exf − ∫exf dx，与前面的 ∫exf dx 相消，只剩边界项 exf。记住这个推导，比记住公式本身重要——它是判据 3 的原型。

例题 15：∫xex/(1+x)2dx（与例题 14 同题，两条路都通）。把 x 写成 (1+x) − 1：

xex/(1+x)2 = ex[1/(1+x) − 1/(1+x)2] = ex[f(x) + f′(x)]，f(x) = 1/(1+x)
答案 = ex/(1+x) + C

对照即可看出两条路的差别：用法二（降阶）是先分部再相消，用法三（抵消）是先凑成 f + f′ 再套公式。同一道题两种写法，说明这两种用法在结构上是同一件事的两个视角。

用法三的推广一：ef(x) 情形

类题：∫(1+sin x)ex/(1+cos x) dx。先把三角部分化简成"某个函数的和与导数"：

(1+sin x)/(1+cos x) = (1/2)sec2(x/2) + tan(x/2) = f′(x) + f(x)，f(x) = tan(x/2)
答案 = extan(x/2) + C

注意这里是先用三角恒等式把式子调成 f + f′，再套母公式。动作顺序是"先化简结构、再识别母公式"，而不是硬拆两个积分。

例题 16（教材）：∫esin x(x cos3x − sin x)/cos2x dx。这里出现的是 ef(x)，母公式中的 ex 换成 esin x 后不再有"求导不变形"的性质，必须真的分部。把被积式拆成两块：

I1 = ∫x cos x · esin xdx，　I2 = −∫(sin x / cos2x)esin xdx

对 I1 分部（dv = cos x esin xdx，故 v = esin x）得 xesin x − ∫esin xdx；对 I2 分部（注意 d(sec x) = sin x/cos2x dx）得 −sec x esin x + ∫esin xdx。两块一相加，∫esin xdx 精确相消：

答案 = esin x(x − sec x) + C

原文判词

难道"分部积分 + 积分抵消"的思想，只能用在被积函数出现 ex 的情形吗？其实也不尽然，有的题目，被积函数中出现的是 ef(x)，甚至都没有指数函数出现，也可尝试该方法。但是对于这种题，就无法利用 [exf(x)]′ = ex[f(x)+f′(x)] 的公式了，必须使用分部积分。 ——讲义考法三（五）注。这条注记把"抵消"从"公式回忆"升级为"结构识别"

用法三的推广二：没有指数函数，靠 PR 结构相消

下面四道题被积函数里都没有指数函数，"抵消"靠的是分子恰好是某个分式的导数（判据 4 的预告）：

题目抵消所依赖的导数关系
∫(1+x−1/x)ex+1/xdx[x ex+1/x]′ = ex+1/x(1+x−1/x)；答案 xex+1/x + C
∫(ln ln x + 1/ln x)dx[x ln ln x]′ = ln ln x + 1/ln x；答案 x ln ln x + C
∫[ln(1+x)−ln x]/[x(1+x)]dx被积式 = −u·u′（u = ln(1+x)−ln x）；答案 −(1/2)ln2((1+x)/x) + C
∫(1−ln x)/(x−ln x)2dx[x/(x−ln x)]′ = (1−ln x)/(x−ln x)2；答案 x/(x−ln x) + C

四道题的动作是同一个：把最复杂的那一块求一次导，看它是否等于分子。这就是下一讲的判据 4。

七讲 6　对复杂部分求导，期待出现奇迹（考法五）

核心判据

把被积函数里最复杂的那一块求一次导，若结果恰好出现在分子上，整个积分就化为 ∫g′/g 或 ∫g′/(1+g) 型，一眼可积。这不是灵感，是例行检查动作——而且这些"巧题"本身就是按这个机制造出来的。

原理拆解：这类题是被"造"出来的

讲义原文直接给出了出题模板，看清楚它，这一讲的题目就全部变成同一道题：

∫(1 + x f′(x)) / (x(1 + x ef(x))) dx = ∫[x ef(x)]′ / [x ef(x)(1 + x ef(x))] dx = ln|x ef(x)/(1 + x ef(x))| + C

模板的构造逻辑只有三步：① 选一个复杂对象 g = x ef(x)；② 算出 g′ = (1 + x f′(x))ef(x)；③ 把被积函数写成 g′/[g(1+g)] 的形式（顺手在分子分母乘 ef(x) 以便隐藏原式）。

如果取 f(x) = arctan x，代入出题模板，稍作变形，即可原创一道题目：∫(1+x+x2)/((1+x2)(x+x2earctan x))dx。 ——讲义考法五注。这条注记把"猜"变成了"验证"

读完这段，做这类题的立场完全变了：不是去猜分母能拆成什么，而是先算 g′，再比对分子。

示例推演：例题 19 与例题 20

例题 19：∫ln x / √(1 + [x(ln x − 1)]2) dx。根号里那个"复杂对象"是

g(x) = x(ln x − 1) = x ln x − x　⟹　g′(x) = ln x + 1 − 1 = ln x

分子正是 g′！于是被积式 = g′/√(1+g2)，这是基本积分表中的反双曲正弦型：

答案 = ln|x(ln x − 1) + √(1 + [x(ln x − 1)]2)| + C

注意 g 的"展开式" x ln x − x 求导时两项恰好消掉一项，这不是巧合，而是设计者刻意选中了一个导数干净的对象。

例题 20：∫(x+1)/(x(1+xex)) dx。试着对分母里的 xex 求导：

(xex)′ = (x+1)ex

分子 x+1 出现了，只差一个 ex。为了补上它，分子分母同乘 ex：

被积式 = (x+1)ex / [xex(1+xex)] = g′/[g(1+g)]，g = xex
答案 = ln|xex/(1+xex)| + C
动作提炼："同乘 ef(x)"是这类题唯一的隐藏动作。它看起来像凭空造出的技巧，实际上是模板第 ③ 步的逆操作——出题人正是靠这一步把 g′/[g(1+g)] 伪装成普通有理式。

类题：∫(1+x cos x)/(x(1+xesin x))dx。同一步动作：(xesin x)′ = esin x(1+x cos x)，分子分母同乘 esin x，答案 ln|xesin x/(1+xesin x)| + C。把 f 从 x 换成 sin x，题还是同一道题。

例题 21 与类题：这一组属于"求导后是分式"的变体，分母是平方，没有 1+g 的结构：

题目关键对象与它的导数
∫(1−ln x)/(x−ln x)2dxg = x/(x−ln x)，g′ = (1−ln x)/(x−ln x)2
∫ex(x−1)/(x−ex)2dxg = x/(x−ex)，g′ = ex(x−1)/(x−ex)2
∫(x + sin x cos x)/(cos x − x sin x)2dxg = cos x/(cos x − x sin x)，g′ 即被积式

三道题的统一动作：先看分母 D，再猜 g = 分子中"某个简单因子" / D，用商的求导公式反推，验证一次即得。第三道题的 g = cos x/(cos x − x sin x) 中"某个简单因子"取 cos x，是三道题里最容易猜错的一个——但验证只需一行，猜错就换一个再试。

常见误区

  • 只盯着分母做裂项，不去对"复杂部分"求导。这是本讲全部题目失分的主因，也是讲义把这一套单独列为一个考法的原因。
  • 求导后看到分子差一个 ef(x) 就以为方向错了。正确的反应是同乘这个因子，而不是换思路。
  • 忘记最后两步的答案形式：g′/[g(1+g)] 积出来是 ln|g/(1+g)|（对数内是比，不是差）；g′ 积出来才是 g 本身。
  • 把"抵消"与"降阶"混同。区分办法：分母是平方、分子是导数 → 直接得 g；分母含 (1+g) 结构 → 得对数比。

八讲 7　三角有理函数的积分（考法六）

所谓三角有理函数，通俗理解就是"三角函数经过有限次加减乘除运算得到的函数"。理论上一律可用万能代换，但万能不等于最快。这一讲的结构是：先记万能代换作为保底，再记五条比它快的特殊通道。

保底通道：万能代换 t = tan(x/2)

核心公式（四个一起记）
t = tan(x/2)　⟹　x = 2arctan t，dx = 2dt/(1+t2)
sin x = 2t/(1+t2)，　cos x = (1−t2)/(1+t2)，　tan x = 2t/(1−t2)

三个三角式的推导骨架是同一个动作：把分母的 1 换成 sin²+cos²，然后上下同除凑 tan。以 sin 为例：

sin x = 2sin(x/2)cos(x/2) / (sin2(x/2)+cos2(x/2)) = 2tan(x/2)/(tan2(x/2)+1) = 2t/(1+t2)

cos 同理（分子用 cos2−sin2），tan 由前两者相除即得。记住这个推导，就不需要死背 tan x = 2t/(1−t2) 这个最易记混的式子。

示例：例题 22 ∫(2−sin x)/(2+cos x)dx。讲义未直接展开，但更省的做法是先把分子拆开：

(2−sin x)/(2+cos x) = 2/(2+cos x) − sin x/(2+cos x)
答案 = (4/√3)arctan(tan(x/2)/√3) + ln(2+cos x) + C

第二块凑 d(2+cos x) 直接得对数，只有第一块需要运用万能代换（或标准公式）。动作提炼：分母是 a + cos x 且分子含 sin x 时，先拆出"分子 = 常数 + 分母的导数"这一块，再对剩下的用万能代换。

类题：∫1/(1+sin x+cos x)dx。万能代换一路到底：

= ∫2dt/(1+t2) · (1+t2)/(2+2t) = ∫dt/(1+t) = ln|1+tan(x/2)| + C

特殊通道 1：分子 = p·分母 + q·(分母)′

适用于 ∫(A sin x + B cos x)/(C sin x + D cos x)dx 形状。原理与例题 22 一样，只是把"常数项"换成"分母的导数"。

例题 23：∫5/(3x+√(1−x2))dx。第一步不是套公式，是做三角换元把根号去掉：令 x = sin t，则 √(1−x2) = cos t、dx = cos t dt：

= ∫5cos t/(3sin t + cos t)dt

现在才是标准形状。设 5cos t = p(3sin t + cos t) + q(3cos t − sin t)（后一项是分母的导数），比对系数得 p = 5/4、q = 5/12：

= (5/4)t + (5/12)ln|3sin t + cos t| + C，最后回代 t = arcsin x

这题的位置容易让人误判：它被讲义放在"三角有理函数"一节，但题面里没有三角函数——关键是先换元造出三角函数结构。

特殊通道 2：积化和差一步秒杀

形如 ∫sin ax·sin bx dx（a ≠ b）或 sin·cos 混合，直接用积化和差，不要分两次分部。

例题 24：∫sin 3x·cos 4x dx。

sin 3x cos 4x = (1/2)[sin 7x − sin x]　⟹　答案 = −(1/14)cos 7x + (1/2)cos x + C
判据的边界：频率相同时（如 ∫sin2x dx）积化和差会得到 cos 0 = 1 的项，转化成降幂公式，仍然有效；但频率不同时若去用降幂公式统一角度（特殊通道 6），反而会把题做长。

对称性三判据：三条最值钱的通道

这三条合起来就是判据 5。检查的对象是 R(sin x, cos x) 在两组符号替换下的变化。

通道 3：R(sin, −cos) = −R(sin, cos) → 凑 d(sin x)

例题 25：∫1/((x2−3)√(1+x2))dx。先做 x = tan t 把根号去掉：

dx = sec2t dt，√(1+x2) = sec t，x2−3 = tan2t − 3
被积式 = sec t/(tan2t − 3) dt = cos t/(4sin2t − 3) dt = du/(4u2−3)，u = sin t
答案 = (1/(4√3))ln|(2x − √3√(1+x2))/(2x + √3√(1+x2))| + C

关键一步是 sec t/(tan2t−3) = cos t/(sin2t−3cos2t)——把分母全部换成 sin 表示，分子就只剩一个 cos t，正好凑 d(sin t)。动作提炼：凑 d(sin x) 之前，先把分母整体改写为"只含 sin x"的形式。

通道 4：R(−sin, cos) = −R(sin, cos) → 凑 d(cos x)

例题 26：∫tan5x/cos x dx。写成 sin/cos 的纯形式：

tan5x/cos x = sin5x/cos6x

分母只含 cos，分子只含 sin 的一次幂（准确说是 sin5，但 sin 的次数是奇数，可以拆出一个 sin 去凑 −d(cos x)）：

令 u = cos x：−∫(1−u2)2/u6du = (1/5)sec5x − (2/3)sec3x + sec x + C

类题：∫1/(sin x + tan x)dx。这题 sin 的次数是 1（奇），但结构上先约简更省：

1/(sin x + tan x) = cos x/(sin x(1+cos x))

此时分子只剩一个 cos x，凑 d(sin x)；也可以直接上万能代换，得 (1/2)ln|tan(x/2)| − (1/4)tan2(x/2) + C。两条都要会，考场上选哪条取决于你当下算得快哪条。

通道 5：R(−sin, −cos) = R(sin, cos) → 造 sec²x d x = d(tan x)

例题 27：∫1/(1+cos2x)dx。分子分母同除 cos2x：

= ∫sec2x/(sec2x + 1) dx = ∫sec2x/(tan2x + 2) dx = ∫dt/(t2+2)，t = tan x
答案 = (1/√2)arctan(tan x/√2) + C

类题 1：∫1/(3sin x + 2cos x)2dx。同除 cos2x：

= ∫dt/(3t+2)2 = −1/(3(3tan x+2)) + C

类题 2：∫(ln tan x)/sin 2x dx。用 sin 2x = 2sin x cos x，再同除 cos2x：

= ∫sec2x·(ln tan x)/(2tan x) dx = ∫(ln t)/(2t)dt = (1/4)ln2(tan x) + C

例题 28：∫sin x cos x/(sin x + cos x)dx。这题有个更干脆的办法：令 t = x − π/4，则分母 sin x + cos x = √2 cos t、分子 sin x cos x = (cos 2t)/2：

= ∫(cos 2t)/(2√2 cos t)dt = (1/√2)∫cos t dt − (1/(2√2))∫sec t dt
答案 = (1/√2)sin(x−π/4) − (1/(2√2))ln|sec(x−π/4)+tan(x−π/4)| + C

类题 1：∫1/(sin6x + cos6x)dx。先用 sin6+cos6 = 1 − 3sin2x cos2x = 1 − (3/4)sin22x 统一到 2x，再同除 cos2造 d(tan)：答案 arctan(2tan 2x) + C。

类题 2：∫sin x cos x/(sin4x + cos4x)dx。同样降幂：sin4+cos4 = 1 − (1/2)sin22x，再令 v = cos 2x，答案 −(1/2)arctan(cos 2x) + C。

特殊通道 6：缩分母

核心判据

分母越复杂，先想办法让它简单。若分母是 1 + cos x，两条路：分子分母乘共轭式 1 − cos x，或用二倍角 1+cos x = 2cos2(x/2)。缩分母是思想，不限于三角。

例题 29：∫1/(1+cos x)dx。二倍角路线最短：

1/(1+cos x) = 1/(2cos2(x/2))　⟹　答案 = tan(x/2) + C

共轭路线给的是 −cot x + csc x + C，两者相差常数。类题 1：∫1/(sin x+cos x)dx = (1/√2)ln|tan((x+π/4)/2)| + C（先把分母合成一个正弦）。类题 2：∫1/(sin x √(1+cos x))dx 走 u = cos x + 再令 v = √(1+u) 两次换元。

原文判词

缩分母的思想，不仅适用于三角有理函数的积分，比如下面这道题也适用。 ——讲义引出例题 30

例题 30：∫dx/(1+√x+√(x+1))。分母里有三个项，其中两项是根式。老办法——有理化两次：

1/(1+√x+√(x+1)) = (√x+√(x+1)−1)/(2√x(√x+√(x+1)))　（乘 √x+√(x+1)−1）
= (√x+√(x+1)−1)(√(x+1)−√x)/(2√x)　（再乘 √(x+1)−√x，利用 (√x+√(x+1))(√(x+1)−√x) = 1）
= [1 + √x − √(x+1)]/(2√x) = 1/(2√x) + 1/2 − (1/2)√((x+1)/x)

前两块直接积出 √x + x/2；第三块令 v = √((x+1)/x) 化为有理式，最终答案含一个 ln(2x+1+2√(x2+x)) 型对数。这道题的教益不是某个技巧，而是"分母复杂就先缩分母"这条思想的迁移能力：从三角迁移到根式，动作完全一样——找共轭并相乘。

特殊通道 7：不同角度先统一角度

被积函数里出现不同角度的三角函数时，先用倍角公式把角度统一，再回落到前面的通道上。

例题 31（1994）：∫1/(sin 2x + 2sin x)dx。用 sin 2x = 2sin x cos x 统一到 x：

= (1/2)∫dx/(sin x(1+cos x))　⟹　缩分母（1+cos x = 2cos2(x/2) 或乘共轭）
答案 = (1/4)ln|tan(x/2)| + (1/8)tan2(x/2) + C

例题 32：∫(cos 2x − sin 2x)/(sin x + cos x)dx。用 cos 2x = cos2x − sin2x 先约掉一个因子：

(cos2x − sin2x)/(sin x + cos x) = cos x − sin x
原式 = ∫[cos x − sin x − 2sin x cos x/(sin x+cos x)]dx

剩余部分把 2sin x cos x 写成 (sin x+cos x)2 − 1，化为 ∫(sin x+cos x)dx − ∫dx/(sin x+cos x)，两块都已知。

例题 33：∫e−sin x·sin 2x / sin4(π/4 − x/2) dx。这题综合度高，但只要按判据走就不会乱：

  1. 统一角度：sin 2x = 2sin x cos x；同时 sin2(π/4 − x/2) = (1 − sin x)/2，故分母 = (1 − sin x)2/4。
  2. 整体化为 8∫e−uu/(1−u)2du，u = sin x（同时约掉了 cos x dx）。
  3. 拆项凑导数：u/(1−u)2 = −1/(1−u) + 1/(1−u)2 = f′ − f，其中 f = 1/(1−u)。
  4. 用 ∫e−u(f′−f)du = e−uf 收尾。
答案 = 8e−sin x/(1 − sin x) + C
本题十分综合，但相信你们已经成长了，现在的你们做这道题应该不成问题。 ——讲义例题 33 注

常见误区

  • 一上来就用万能代换，把一个两行能解决的题做成四次有理式。
  • 对称性判据只检查了 sin 或只检查了 cos，没把三组都查一遍。三组是"检查清单"，漏一组就可能白算一大段。
  • 通道 3/4 里忘了先把分母整体改写成"只含 sin"或"只含 cos"的形式，导致凑不出 d(sin x)/d(cos x)。
  • 把"缩分母"局限在三角里。例题 30 说明它是一个通用的分母化简动作。
  • 通道 5（R(−sin,−cos) = R）与"万能代换"混同：前者得到 d(tan x) 的有理式，后者得到 dt 的有理式，速度差一个量级。

九讲 8　隐函数的不定积分（考法七·选学）

核心判据

曲线由方程给出时，不要试图解出 y = y(x)，而是换一个参数 —— 直接把积分里反复出现的那一坨设为新变量，让方程把它变成有理式。

示例推演：例题 34

设 x = x(y) 由方程 x(y−x)2 = y 确定，求 ∫dx/(y−x)。

积分里反复出现 y − x，就令 u = y − x（即 y = x + u）。代回方程：

x u2 = x + u　⟹　x(u2 − 1) = u　⟹　x = u/(u2 − 1)

于是原积分化为 u 的有理函数积分（对 x 求导得 dx = −(u2+1)/(u2−1)2 du）：

∫dx/(y−x) = −∫(u2+1)/(u(u2−1)2) du

待定系数裂项（A = 1、B = D = −1/2、C = 1/2、E = −1/2）后逐项积分，再用关系式 u2 − 1 = u/x 把答案化简回原变量：

答案 = −(1/2)ln|x(y−x)| + x/(y−x) + C
为什么必须换参：直接对 x(y−x)2 = y 隐式求导会得到一个含 y′ 的式子，再回代进积分无法化简。而"把 y − x 设为参数"一步就让方程变成显式的有理式。选参数的判据：选积分中反复出现的那个表达式。

常见误区

  • 强行解出 y = y(x)。本题中 y 满足三次方程，解出来也无法积。
  • 设了 u = y − x 之后忘记把 x 也换成 u 的表达式（本题中 x = u/(u2−1) 由方程给出，不是恒等式）。
  • 最后不回代，或回代时漏掉用 u2−1 = u/x 化简这一步，答案里留着 u。

十二检验理解

二十道题，每题只有一个选项与判据一致。点选即判定并显示解析；作答记录保存在本机浏览器中。

  • 1. 分段函数求不定积分时，两段各自写完任意常数后还要做一步"拼接"。这一步依据的是原函数在哪一点上的什么性质？

    拼接只需要原函数在分界点连续这一条。原函数是否可导，由被积函数在该点是否连续自动决定——那是结论式的性质，不需要也不应该拿来做检查条件。

  • 2. 处理 ∫1/(x6(1+x2))dx 的"改造分子"通道时，反复使用的是哪条恒等式？

    把 1 写成 (1+x²) − x²，每用一次就把分母的 x 次数削掉 2；连用三次后只剩幂函数与 1/(1+x²) 两类基本积分。"1 + x⁶ 拆成两个二次因式之积"和"1 + x⁴ = (1+x²)² − 2x²"是另外两族题用的恒等式。

  • 3. 计算 ∫(1+x2)/(1+x4)dx，分子分母同除 x2 后，分母变成什么形式？

    同除 x² 得 x² + 1/x²，而 x² + 1/x² = (x − 1/x)² + 2，同时分子变成 1 + 1/x²，恰好是 d(x − 1/x)。"包含 (x+1/x)² 的两种写法"属于分子取 1 − x² 的那一类题。

  • 4. 若把 1+x4 分解成 (1+x2+√2 x)(1+x2−√2 x) 再走待定系数，讲义对这条路的评价是？

    因式分解在代数上完全正确（(1+x²)² − 2x² = 1 + 2x² + x⁴ − 2x² = 1 + x⁴），问题在于之后要解四元一次方程组、还要对两个二次因式分别收尾。配对法两步就能出结果，所以优先配对法。

  • 5. 用"令整个根号等于 t"去根号、并且已经算完关于 t 的积分之后，做不定积分时还有哪一步绝对不能省？

    不定积分的结果必须用原变量表示，回代是最后一步的固定动作。给结果求导验证属于自检，考场上不写；换元的单调性与可逆区间在不定积分里不影响答案形式（定积分才需要连积分限一起换）。

  • 6. 对 ∫1/∛((x+1)2(x−1)4)dx，讲义示范的换元是令哪个表达式等于 t？

    两个一次因式的幂指数分母相同（都是 3），令它们的比值开三次方，反解出 x 之后所有分式因式连根号一起精确相消，只剩 (3/2)t⁻² dt。"∛(x−1) 与 ∛(x²−1)"都只能带走一部分根号，剩下一部分仍然留在式子里。

  • 7. 计算定积分 ∫01 arcsin√x / √(x(1−x)) dx，最有效的换元是？

    取 x = sin²t 后，√(x(1−x)) 正好等于 sin t·cos t，而 dx 里的 2sin t·cos t 把它完全约掉，整个被积式塌缩成一个 2t，积分值直接得 π²/4。这里的钥匙不是根号，是 arcsin：它的反函数能把两个根式一起带走。

  • 8. ∫x·ln(1+x2)·arctan x dx 做分部时，d 后面配的是 (1+x2)/2 而不是 x2/2。这样选的目的是？

    分部后的待积项里含 ln(1+x²) 的导数为 2x/(1+x²)，而配出的 v 恰好带一个 (1+x²) 因子，两者相乘正好消成 2x，于是只剩一个已知的 ∫x arctan x dx。配 x²/2 就不会发生这种相消，后面要多算一大段。

  • 9. 对 ∫e2x arctan√(ex−1) dx 令 t = √(ex−1) 之后，被积式变成什么？

    eˣ = 1 + t² 给出 e²ˣ = (1+t²)²，dx = 2t/(1+t²) dt，两者相乘时约掉一个 (1+t²)，剩下 2t(1+t²)arctan t。这个形状正是"多项式 × 反三角"，可以直接分部。

  • 10. "分部 + 抵消"战术的母公式是哪一个？

    母公式是 ∫eˣ[f + f′]dx = eˣf + C，它的推导本身就是"拆两块、一块分部"：∫eˣf′dx 分部后得到 eˣf − ∫eˣf dx，与原式中的 ∫eˣf dx 相消，只剩边界项。另外两个选项分别漏掉了 f 项、或把 eˣ 换成了 f 本身。

  • 11. 计算 ∫esin x(x cos3x − sin x)/cos2x dx 时，式子里的 ∫esin xdx 最后被消掉，靠的是什么动作？

    这里指数上是 sin x 而不是 x，母公式失效，必须真的分部：第一块取 dv = cos x·e^{sin x}dx，分部后冒出 −∫e^{sin x}dx；第二块注意到 sin x/cos²x 就是 (sec x)′，分部后冒出 +∫e^{sin x}dx，两者相互抵消。最终答案里没有 e^{sin x} 的积分项。

  • 12. 求 ∫(x+1)/(x(1+xex))dx 时，发现 (xex)′ = (x+1)ex，与分子只差一个 ex。接着该做什么？

    分子分母同乘 eˣ 后，被积式变成 (xeˣ)′ / [xeˣ(1 + xeˣ)]，正好是 g′/[g(1+g)] 的形状，积分立刻得到 ln|xeˣ/(1+xeˣ)| + C。这个"同乘 e^{f(x)}"的动作，正是出题人用来把 g′/[g(1+g)] 伪装成普通有理式的逆操作。

  • 13. 对 ∫ln x / √(1+[x(ln x − 1)]2) dx，把 g(x) = x(ln x − 1) 求一次导，结果是？

    g = x ln x − x，求导时 (x ln x)′ = ln x + 1 与 x 的导数 1 精确相消，只剩 ln x——恰好是被积式的分子。于是整个积分就是 ∫g′/√(1+g²)，属于基本积分表里的反双曲正弦型。

  • 14. 判断出 R(sin x, −cos x) = −R(sin x, cos x) 之后，接下来的动作是？

    "R 关于 cos 是奇的"意味着式子里 cos 只以奇次幂出现，因此可以整体改写为只含 sin x（把 cos² 换成 1 − sin²，留下一个 cos 去配合 dx 凑成 d(sin x)）。"同除 cos² 造 d(tan x)"属于三条判据里的第三条，对应的是"关于 sin 和 cos 同时为偶"的情形。

  • 15. 若 R(−sin x, −cos x) = R(sin x, cos x)，最省的动作是？

    同时关于 sin 和 cos 是偶的，说明 sin、cos 的总次数为偶，同除 cos² 后式子变成只含 tan x，剩下的 sec²x dx 正是 d(tan x)。例：∫1/(1+cos²x)dx 同除 cos²x 后化为 ∫dt/(t²+2) = (1/√2)arctan(t/√2) + C。

  • 16. 万能代换 t = tan(x/2) 之下，tan x 等于？

    把 sin x 与 cos x 的表达式相除：tan x = [2t/(1+t²)] ÷ [(1−t²)/(1+t²)] = 2t/(1−t²)。分母是 1 减 t² 而不是 1 加 t²，这是最容易记混的一处。选项里 2t/(1+t²) 是 sin x，(1−t²)/(1+t²) 是 cos x。

  • 17. ∫sin 3x·cos 4x dx 用积化和差一步化解，正确的拆分是？

    sin A cos B = (1/2)[sin(A+B) + sin(A−B)]，取 A = 3x、B = 4x 得 (1/2)[sin 7x + sin(−x)] = (1/2)(sin 7x − sin x)。积分结果是 −(1/14)cos 7x + (1/2)cos x + C。

  • 18. 处理 ∫dx/(1+√x+√(x+1)) 时，第二次有理化乘的因子是？

    第一次乘 √x + √(x+1) − 1 之后，分母变成 2√x(√x + √(x+1))；再乘 √(x+1) − √x，利用 (√x+√(x+1))(√(x+1)−√x) = 1，分母只剩 2√x，被积式化为 1/(2√x) + 1/2 − (1/2)√((x+1)/x) 三块。这就是"缩分母"从三角迁移到根式的样子。

  • 19. ∫xex/(1+x)2dx 走"分部降分母阶"这条路时，取 u = xex、dv = dx/(1+x)² 的理由是？

    降阶后剩下的分母是 1/(1+x)，而 (xeˣ)′ = (x+1)eˣ 带一个 (x+1)，两者相乘直接消成 eˣ，立刻可积。选 u 的判据不是"谁次数高"，也不是"反三角优先"那条口诀，而是"谁的导数能约掉降阶后剩下的分母"。

  • 20. 隐函数题：由 x(y−x)2 = y 求 ∫dx/(y−x)。第一步应该设哪个量为参数？

    选参数的判据是"积分里反复出现的那个组合"，这里就是 y − x。令 u = y − x 后代回方程得 x(u² − 1) = u，即 x = u/(u²−1)，方程一步变成显式有理式，再走待定系数裂项即可。强行解出 y = y(x) 会撞上三次方程，解出来也无法积。
