## 四、铁律（红线，逐条可检查）

1. **每题六节齐全**：题目 / 考点定位 / 考场分析 / 解题步骤 / 答案 / 易错提醒，一节不省；「解题步骤」内部按模板六步（看结构 → 等价变形 → 构造或选工具 → 算关键量 → 推导判号 → 收口）推进。
2. **不许跳步**：不得出现「略」「同理可证」「由例题 X 可得」「留给读者」式省略；每一步推导、每一个放缩都要写出依据，长题拆成多个单行公式。
3. **正文严禁叙述参考材料**：不得出现「板书 / 手稿 / 手稿说 / 原法照录 / 讲过 / 略 / 参考讲义」等字样——手稿只用于理解思路，写出来必须是自己完整的解答。
4. **不因参考材料缺失而省略**：手稿缺的题（如专题 2 手稿标注缺的题）必须独立完整求解；专题 9 的题面与手写解答混排，仍以题面文件对账、逐题写全。
5. **答案必须独立验证**：用到 sympy 或数值抽样双路核对（极限值、积分值、导数、极值、幂级数系数等）；含参数的结论要说明参数的临界值与最优性；等式题写清等号成立条件。**手稿若有笔误，以验算为准，正文只写正确结论，不要写「某处笔误」之类叙述。**
6. **公式排版规范**（防 KaTeX/PDF 渲染出错）：
   - `$…$`、`$$…$$` 内**禁止中文**与①②圈码；
   - 每条 `$$…$$` 必须**单行**；不用 `aligned`/`cases`/`\\` 换行；衔接词（于是/即/故）写在公式外，不用 `\Longrightarrow`/`\Longleftrightarrow` 连接多行推导；
   - 不用 `\underbrace`/`\overbrace`；`\boxed{}` 内只放纯结果；
   - `\lvert`、`\rvert` 后面不能紧跟字母（写成 `\lvert f\rvert`），表格单元格内尽量避免裸 `|`。
7. **体例与术语对齐 10~13**：凹凸按同济口径（`$f''>0$` 为凹）；充要条件题分「从前推后／从后推前」；每题给出「坑与临界／预计用时」；等号与最优性逐题交代。

## 五、PDF 生成链路（本机已验证可跑通，无需联外网）

1. **依赖（均已就位）**：
   - `C:\Users\天梦\.workbuddy\binaries\node\workspace\node_modules\marked\lib\marked.cjs`（marked 15）
   - `…\node_modules\katex\dist\katex.min.js`、`katex.min.css` 与 `dist\fonts\*.woff2`（20 个）
   - Chrome：`C:\Program Files\Google\Chrome\Application\chrome.exe`
   - KaTeX 渲染器副本（TreeWalker 版）：`F:\WorkSpace\kaoyan\shuxue\.workbuddy\tmp\extracted_renderer.js`
2. **构建脚本**（写一个 `build.mjs` 放临时目录；产物目录 `.build_pdf/` 已被 .gitignore 忽略）：
   - ESM 里用 `createRequire(import.meta.url)` + **绝对路径** require `marked.cjs`（ESM 下 NODE_PATH 无效）；
   - **先抽公式再走 marked**（关键）：用 `/\$\$([\s\S]+?)\$\$|\$([^$]+?)\$/g` 把公式换成 `@@MATH0@@` 占位，`marked.parse` 之后再回填，并对 `&`→`&amp;`、`<`→`&lt;` 转义；否则公式里的 `_`、`*`、`|` 会被当 Markdown 语法吃掉（`|` 还会拆坏表格）；
   - HTML 内联 `katex.min.css` + 字体，用 KaTeX 渲染（`throwOnError:false`）后交给 Chrome 打印；
   - Chrome：`chrome.exe --headless=new --disable-gpu --no-pdf-header-footer --run-all-compositor-stages-before-draw --virtual-time-budget=30000 --print-to-pdf=out.pdf "file:///…/doc.html"`；中间 HTML 用**纯 ASCII 文件名/路径**（中文名先复制成 `docN.html`），结束后把产物改成目标中文名；
   - CSS 要点：`table` **不要**加 `break-inside: avoid`（二十几行的长表会被整体推到下一页、留大片空白），改为只给 `tr` 加 `avoid` 并 `thead{display:table-header-group}`（表头跨页重复）；`h2/h3/h4` 加 `break-after: avoid`（标题不落页尾）。
3. **PDF 校验**：用 pymupdf 回读 → `$` 计数 0、`\frac` 计数 0、KaTeX 字体已内嵌；再 `get_pixmap(dpi≈105)` 导 1–2 页 PNG **肉眼核对版面**（无空页、公式不溢出、表格不炸）。
