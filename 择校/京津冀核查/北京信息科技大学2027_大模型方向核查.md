## 一、结论速览

**有大模型方向，而且不是挂名。**

1. **学院层面**：主力是 **005 计算机学院** 与 **003 自动化学院（人工智能学院）**；次要落点是 004 信息与通信工程学院、010 理学院、002 仪器科学与光电工程学院、006 管理科学与工程学院、009 传播艺术与科学学院。11234
2.
3. **单位层面**：学校 2024-11 成立 **人工智能研究院**，2026-03 正式揭牌 **人工智能学院**（与自动化学院一套人马两块牌子）；建有 **中国商业联合会大模型智能应用与安全计算重点实验室**、**"可信决策人工智能技术"北京市重点实验室**、**"具身智能灵巧操作"北京市重点实验室**（全国首个该类省级重点实验室）；**校级算力平台配 GPU + 训推一体，原文写明"可满足大模型推理、微调和检索增强的任务需求"**。
4. **导师层面**：至少 7 位导师在官方简介里**逐字写了"大模型 / 大语言模型"**。
5. **附带发现**：BISTU 是 **22408 大户**——085404 计算机技术（99 人）、085412 网络与信息安全（23 人）、085410 人工智能 03 智能计算（12 人）全部考「英二 + 数二 + 408」。
6. **定位提示**：BISTU 为北京市属双非，一志愿复试线直接采用 **A 类地区国家线**（非自划线），报考门槛与天津大学（11408、校线 315）不在一个量级。

## 五、报考要点备忘

1. **走国家线**：2026 年一志愿考生进入复试的基本分数线 = **2026 年 A 类地区国家分数线**（非自划线）；退役大学生士兵计划为 A 类线总分降 25 分、单科不降。调剂线由各学院自主确定。
2. **复试构成**：复试成绩百分制（笔试 × a + 面试 × b）；入学总成绩中**复试占比 30%–50%**；**原则上不进行破格复试**；同等学力需加试两门本科主干课。
3. **计算机学院复试统一考 C 语言机试**——与天大「计算机学科综合」的笔试型复试路径不同。
4. **22408 与 11408 在同一学院内并存**：例如计算机学院 081200/083900（学硕）考 11408，而 085404/085410-03/085412（专硕）考 22408。选方向时务必看清。
