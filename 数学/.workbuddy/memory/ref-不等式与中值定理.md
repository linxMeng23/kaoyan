# 方法库 · 不等式与中值定理（从 MEMORY.md 拆出，答题前按需读）

## 不等式通用判据

- 先看余量阶（两端展开到首个不相等项）：一阶→一阶放缩；三阶→二阶泰勒；四阶→同阶泰勒两头夹；≥5→泰勒或已知不等式。
- 型别→手法：乘积非负型→拆因子 + 辅助函数单增 + 零点重合；分式型→去分母再求导；两端同阶相消→两头夹；$A<f<B$ 型→两端是端点值或端点极限 + 主干证严格单调，极限端补严格性（反证 + 极限=上确界）。
- 泰勒扔余项：符号 = $f^{(n+1)}(\xi)$ 符号 × $(x-x_0)^{n+1}$ 符号；仅当 $f^{(n+1)}$ 在区间保号可扔（恒正→$f\ge P_n$，恒负→$f\le P_n$）；$n$ 奇偶改号，双侧分侧讨论。坑：$\sin x$ 与 $x-\frac{x^3}6$ 在 $x>\sqrt6$ 反向。
- $(\sin x/x)^n>\cos x$：$n=2$ AM-GM 可证；$n=3$ 须 $x^4$ 精度泰勒或降幂法（平方版引理推不出立方版）。
- 三角有理式：找翻转恒等式（$\frac1{\tan^2x}=\frac1{\sin^2x}-1$）写成 $1-F$ 再求导；端点常数靠 $\frac1{\sin^2x}=\frac1{x^2}+\frac13+\frac{x^2}{15}+\cdots$。
- 指数和型：先看两指数之差，差为整数可把「和」并成「积」整体求导；两项单调性反向不可分别判断后相加。
- 含参数条件（如 $k>\ln2-1$）要判「顺风条件」还是「临界条件」，给真实临界值。
- 姊妹题自测：把主证引理降一阶（立方→平方）造结构相同、可简证的题。

## 积分因子 / 微分不等式

- 识别表：$f'+f\to(e^xf)'$；$f'-\lambda f\to(e^{-\lambda x}f)'$；$f'+pf\to e^{\int p}f$；$xf'+f\to(xf)'$；$f'/f$（$f>0$）$\to\ln f$；$f'-f\tan x\to f\cos x$。造完走「$g'$ 定号→单调→与 $g(x_0)$ 比」。
- 一阶例（$f(0)=0$、$f'+f>0$ ⟹ $x\ge0$ 时 $f\ge0$）：$g=e^xf$、$g(0)=0$。$x\ge0$ 非装饰（全轴则 $x<0$ 反例）；充分非必要（$f=x^2e^{-2x}$）。
- 二阶常系数（$L=(D-r_1)(D-r_2)$）三步：① 验比较函数是齐次解；② 作差 $g=f-Y$ 归零初值；③ 两个一阶因子由内到外各用一次积分因子。Green 形式最省：$g(x)=\int_0^x[e^{r_2(x-t)}-e^{r_1(x-t)}]Lg(t)\mathrm dt$，核非负 ⟹ 源项非负 ⟹ $g\ge0$。坑：漏验齐次解；$g'-3g\ge0$ 不是 $g\ge0$。

## $f''>0$（凹）族

- **例题9 母不等式（背）**：切线式 $f(x)\ge f(x_0)+f'(x_0)(x-x_0)$；中点式 $f(\frac{x_1+x_2}2)\le\frac{f(x_1)+f(x_2)}2$（在中点写两次切线式相加即得）。坑：$f''>0$ 须在含全部点的区间成立；等号仅 $x=x_0$ 或 $x_1=x_2$。产出：$-\ln x$→AM-GM；$e^x$→$\sqrt{ab}\le\frac{a+b}2$；$x^2$→平方均值。
- 例题8（1995）：$\lim_{x\to0}f/x=1$、$f''>0$ ⟹ $f\ge x$。题眼 $f(0)=0,f'(0)=1$，$y=x$ 是切线。易错：$x<0$ 反号（$f-x=x[f'(\xi)-1]$ 负负得正）；禁写 $f\sim x\Rightarrow f\ge x$。
- 例题10（$x^p$ 二元 Jensen）：判方向只看 $f''=p(p-1)x^{p-2}$——$p>1$ 或 $p<0$ ⟹ ≥；$0<p<1$ 反向；$p=1$ 恒等。二点中点式只能迭代 $2^n$ 点。
- 例题11：$f''f-(f')^2>0$ 的真身是 $(\ln f)''>0$，令 $g=\ln f$ 套例题9。判据：见「乘积减平方」想 $(\ln f)''$ 的分子。蕴含 $f''>0$ 但反之不成立。

## 中值定理证不等式（例题 12–19）

- 例题12（2006）：$f'>0,f''>0,\Delta x>0$ ⟹ $0<dy<\Delta y$；$dy$ 与 $\Delta y$ 大小只由 $f''$ 符号定。
- 例题13（差商−导数三步）：在 $y$ 处展开 $f(x)$ → 移项除 $x-y$ → $|f''|\le M$ 放大得 $\frac M2|x-y|$。坑：$x=y$ 补；两次 LMVT 只给系数 1；$\sin''=-\sin$。
- 例题14（2025）：三点差商严格递增 ⟺ $f'$ 严格增。充分性通道：$t\to u^+,v^-$ 得 $f'(u)\le C\le f'(v)$；极限磨掉严格号须反证补回。
- 例题15（2004）：$e<a<b<e^2$ ⟹ $\ln^2b-\ln^2a>\frac4{e^2}(b-a)$。形状=端点差+$(b-a)$→LMVT；常数溯源 $g'(e^2)=\frac4{e^2}$、$g''<0$（$x>e$）。要点：LMVT 后必须回 $\xi$ 范围估值；$b<e^2$ 不可少；$\frac4{e^2}$ 最优取不到。
- 例题16（$t\ln t$ 超可加性）：$(1+a)\ln(1+a)+(1+b)\ln(1+b)<(1+a+b)\ln(1+a+b)$。两通道：① 单元辅助函数一次 LMVT；② **板书路线（用户指定）**：化归 $f(a)-f(0)<f(a+b)-f(b)$，配等长子区间（WLOG $b\ge a$）两次 LMVT，靠 $f'$ 严格递增收尾。方法论：超可加结构先找等长子区间，中值系数才能约掉。
- 例题17（2002）：$\frac{2a}{a^2+b^2}<\frac{\ln b-\ln a}{b-a}<\frac1{\sqrt{ab}}$。左边 LMVT 成功（$\xi<b$）；**右边 LMVT 失效**（需 $\xi>\sqrt{ab}$，给不到），正解齐次换元回母不等式。结论：中值定理会失效，重心是「构造函数 + 求导判单调」。
- 例题18：内部取最小值 → 费马 $f'(c)=0$；对 $f'$ 分段 LMVT 相加消 $c$。
- 例题19（Cauchy 版）：$\frac{\arctan x}{\ln(1+x)}\le\frac{1+\sqrt2}2$，得 $\frac{1+\xi}{1+\xi^2}$ 后不追问 $\xi$，直接求全局最值（$t=\sqrt2-1$）。上界非最优，不可写「等号当且仅当」。
- 类题（右端含 $x$ 时必须用 $\xi<x$）：$\sqrt{\frac{1-x}{1+x}}<\frac{\ln(1+x)}{\arcsin x}$，靠 $\varphi$ 递减；照搬全局最值得无用界。

## 母不等式与常备引理

- 例题1 母不等式四张等价面孔：$(1+x)\ln^2(1+x)<x^2$ ⇔ $\ln(1+x)<\frac{x}{\sqrt{1+x}}$ ⇔ $\frac{\ln t}{t-1}<\frac1{\sqrt t}$ ⇔ $\ln^2(1+\frac1x)<\frac1{x(1+x)}$。
- 立方版降幂法：$(\sin x/x)^3>\cos x$ ⇔ $\tan x\sin^2x>x^3$；$H=\tan x\sin^2x-x^3$，配二阶下界 $\tan x>x+\frac{x^3}3$、$\sin x>x-\frac{x^3}6$ 得 $H'>\frac{x^6}6>0$。
- $\sin x/x$ 族：$\frac2\pi<\frac{\sin x}x<1$；平方版（AM-GM）；立方版（降幂法）。
- 类题1（$x^{\frac{x}{1-x}}+x^{\frac1{1-x}}$）路线（用户指定）：直接设 $f$；先算两端极限（$1$、$\frac2e$）；分别求导后用恒等式 $x^{\frac1{1-x}}=x\cdot x^{\frac{x}{1-x}}$ 合并；判号归结 $\ln x<\frac{2(x-1)}{1+x}$；得 $\frac2e<f<1$。
- 类题2（$\frac1{x^2}-\frac1{\tan^2x}$）：$f=1-F$、$F=\frac1{\sin^2x}-\frac1{x^2}$；端点 $\frac23$、$\frac4{\pi^2}$；副产品 $\frac1x-\cot x>\frac x3$。
