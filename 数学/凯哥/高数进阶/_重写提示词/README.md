## 九个提示词共有的六条约定

1. **手稿优先（约定 A）**：手稿写的那条路就是正文主线；手稿之外的做法一律降为 `**另解：xxx**`；手稿打叉／涂改的错解保留进「易错提醒」。
2. **强制逐页读手稿**：先 `pypdfium2_cli render` 转 PNG，再用 read 逐页看。不许凭现有 md 或记忆推断。
3. **先列清单再动笔**：读完手稿先输出「页码对应 + 逐题主线 + 降级清单 + 打叉清单 + 穿插知识点清单」，**停下来等确认**才开写。题量大的（专题 2、5、8）还要给分批方案。
4. **穿插知识点不单列附录**：按手稿出现位置就近写进对应题内（`手稿旁注：` / `手稿口诀：`）；通篇复用的工具表才留在第零节。
5. **只改 md，不构建 PDF**。
6. **写前备份 .bak，写后删临时目录**，并做数学核验（sympy / numpy 数值验证；**本机 python 没有 scipy，不要 import scipy**）。
